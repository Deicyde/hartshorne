# Cycles, rational equivalence, and Chow groups

This subchapter defines codimension-graded cycles on varieties, rational
equivalence through divisors on normalizations, and the resulting Chow
groups. Raw cycle pushforward is kept separate from its descent to Chow
groups. The base field is algebraically closed and all statements are valid
in arbitrary characteristic.
