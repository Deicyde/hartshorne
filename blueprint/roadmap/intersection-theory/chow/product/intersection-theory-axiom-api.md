# The A1–A7 intersection-theory interface

For a class of nonsingular quasi-projective varieties closed under products,
package codimension-graded intersection pairings, arbitrary-morphism
pullbacks, and proper-morphism pushforwards, together with Hartshorne's axioms
A1–A7: graded-ring laws, functorialities, projection formula, diagonal
reduction, local proper-intersection expansion, and Cartier-divisor
normalization.

The interface is a specification. Its existence is a separate blocked
theorem, and no product is installed on Chow groups merely by defining this
structure.
