# Chern character of an invertible sheaf

For an invertible sheaf $\mathcal{O}_X(D)$,

$ch(\mathcal{O}_X(D))=\exp (D)=1+D+D^2/2+D^3/6+\ldots$

in $A(X) \otimes Q$, truncated above $\dim X$.
