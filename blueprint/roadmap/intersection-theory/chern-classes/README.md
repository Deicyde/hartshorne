# Chern classes in the Chow ring

For nonsingular quasi-projective varieties over the algebraically closed base
field, this chapter defines Chern classes from the Chow projective-bundle
formula and records Hartshorne's properties C1–C7.  The algebraic statements
are characteristic-free.  Formal Chern roots are bookkeeping after an
injective splitting pullback, never chosen roots in the original Chow ring.
