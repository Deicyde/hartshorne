# The rings of a projective variety

For an affine variety, Hartshorne's Theorem I.3.2 describes its
[coordinate ring](../global-regular-eq-coordinate-ring.md),
[local rings](../local-ring-is-localization.md), and
[function field](../function-field-is-fraction-field.md). For a projective
variety, Theorem I.3.4 gives a different description: global regular
functions are constant, $\mathcal{O} (Y) = k$, while the local rings and
function field are obtained from graded localizations of $S(Y)$.

The local-ring and function-field statements reduce to the affine case
on each standard chart. The chart maps are isomorphisms of varieties,
so they identify regular germs and rational functions with their affine
counterparts. Graded localization expresses those affine descriptions
in homogeneous coordinates.

The assertion about global regular functions uses the whole affine cover.
Its integrality argument bounds the readings of one regular function
on every chart. This contrasts with the affine case, where the coordinate
ring contains all global regular functions, and helps motivate the use
of sheaves and cohomology in the later chapters.

The identification of $K(Y)$ with $S(Y)_{((0))}$ is compatible with all
chart readings. A rational function therefore has one homogeneous
description even when it is represented on different affine charts.
