# Stalks of module sheaves

The stalk of a module sheaf at a point is a module over the local ring there,
and it is computed by an adjunction with the skyscraper sheaf at that point.
This chapter records that adjunction and uses it to compute the stalks of the
pullback of a module sheaf, which the stalkwise flatness arguments of
Hartshorne III.9 need.

1. [Skyscraper module sheaves and the stalk adjunction](module-skyscraper-stalk-adjunction.md)
2. [Stalks of the pullback of a module sheaf](module-pullback-stalk.md)

These results build on the [modules and quasi-coherent sheaves](../modules-and-quasicoherent/README.md) chapter.
