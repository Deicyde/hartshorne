# Global sections of Spec

For every commutative ring `A`, the canonical constant-section map is a ring
isomorphism

`A ≅ Γ(Spec A, 𝒪_{Spec A})`.

This is Proposition 2.2(c), the `f = 1` case of the principal-open calculation.
