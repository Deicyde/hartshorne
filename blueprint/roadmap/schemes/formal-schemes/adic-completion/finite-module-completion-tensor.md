# Finite-module completion as tensor product

If `A` is Noetherian and `M` is a finite `A`-module, the canonical map is a
linear equivalence

`Ahat tensor_A M ≃ Mhat`.

This is an ordinary algebraic tensor product. No completed tensor-product
construction is introduced.
