# Formal completions and formal schemes

This chapter covers Hartshorne II.9: inverse systems, adic completion, formal
neighbourhoods, Noetherian formal schemes, and coherent formal modules. It
uses natural-number systems with the `n`th thickening cut out by `I^(n+1)`.

Hartshorne's formal schemes are plain locally ringed spaces with finite covers
by algebraizable affine charts. The project notation `Spf_I(A)` is introduced
only through an explicit representation bridge; it does not change the
source's morphisms into continuous maps of topological rings.

Read the milestones in this order:

1. [Inverse systems and Mittag–Leffler exactness](inverse-systems/README.md)
2. [Adic completion](adic-completion/README.md)
3. [Formal neighbourhoods and formal spectra](formal-neighborhoods/README.md)
4. [Coherent modules on formal schemes](coherent-formal-modules/README.md)

Exercise 9.6 and its Picard-limit consequences are deferred because their
later use is confined to the exercise-only chain beginning at III, Exercise
11.5. The pathologies in III, Exercise 11.7 are retained in the source notes
without adding forward DAG edges.
