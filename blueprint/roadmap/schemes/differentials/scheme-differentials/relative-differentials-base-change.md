# Base change for differential sheaves

Let `X' = X ×_Y Y'`, with projections `g' : X' → X` and `f' : X' → Y'`.
There is a canonical isomorphism of `𝒪_{X'}`-modules

`Ω[X'/Y'] ≅ g'^* Ω[X/Y]`,

compatible with the universal derivations.
