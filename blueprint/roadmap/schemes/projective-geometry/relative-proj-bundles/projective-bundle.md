# Projective bundles

Let `X` be Noetherian and `E` finite locally free. Define
`P(E) = Proj_X Sym(E)` using the quotient convention. If `E` is free of rank
`n + 1` on `U`, identify `P(E)|_U` with `P^n_U`, compatibly with the projection
and `O(1)`.
