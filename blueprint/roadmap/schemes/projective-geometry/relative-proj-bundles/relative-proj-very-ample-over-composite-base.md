# Very ampleness over a composite base

Let `X -> Y` be of finite type, let `L` be ample on `X`, and let
`P = Proj_X S`. For all sufficiently large `n`,
`O_P(1) tensor pi^* L^n` is very ample on `P` relative to `Y`.
