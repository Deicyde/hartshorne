# Eliminating the base locus of a linear system

Let finitely many sections of an invertible sheaf define a morphism to
projective space on their common generation locus. Form their base ideal by
local trivialization and blow it up. The pulled-back sections then generate an
invertible subsheaf everywhere and define a morphism extending the original
one. For a linear system this makes its pullback base-point-free.
