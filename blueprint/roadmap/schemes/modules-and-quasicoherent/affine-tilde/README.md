# The affine tilde construction

For a ring $A$, an $A$-module $M$ determines the sheaf $\widetilde{M}$ of
modules on $\operatorname{Spec}A$, with stalks $M_{\mathfrak p}$ and sections
$M_f$ on principal opens (Proposition 5.1).  The tilde functor is fully
faithful and exact, commutes with tensor products and direct sums, and
describes pullback and pushforward along morphisms of affine schemes
(Proposition 5.2); it is left adjoint to global sections (Exercise 5.3).
