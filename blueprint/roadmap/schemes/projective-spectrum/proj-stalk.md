# The stalk of Proj

For every $\mathfrak{p} \in \operatorname{Proj} S$, the structure-sheaf stalk is naturally isomorphic to
the degree-zero homogeneous localization:

$\mathcal{O} _{\operatorname{Proj} S,\mathfrak{p} } \cong S_{(\mathfrak{p} )}$.

Evaluation supplies the map; a same-degree fraction is represented on a basic
neighbourhood, while equality in the localization permits shrinking.  This is
Proposition 2.5(a).
