# Degree-one basic opens cover Proj of a degree-one-generated ring

Let $S=\bigoplus_{d\ge 0}S_d$ be a graded ring that is generated by $S_{1}$ as an
$S_{0}$-algebra. Then for every point $\mathfrak{p}\in\operatorname{Proj}S$ there is some
$f\in S_{1}$ with $f\notin\mathfrak{p}$. Equivalently, the open sets $D_{+}(f)$ for
$f\in S_{1}$ cover $\operatorname{Proj}S$.

Every element of $S$ is a polynomial over $S_{0}$ in elements of $S_{1}$, so every element of
the irrelevant ideal $S_{+}$ lies in the ideal generated by $S_{1}$. If $\mathfrak{p}$
contained $S_{1}$, it would therefore contain $S_{+}$, which a point of
$\operatorname{Proj}S$ does not.
