# Cancellation for finite type

If $f : X \to Y$ is quasi-compact and $g \circ f : X \to Z$ is finite type, then $f$ is finite type.

The quasi-compactness hypothesis supplies one part of finite type.
Local finite type cancels from the composite by the corresponding
ring-homomorphism criterion.
