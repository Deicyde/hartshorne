# Integral if and only if reduced and irreducible

A scheme is integral if and only if it is both reduced and irreducible.

An integral scheme has no nontrivial product decomposition of sections over disjoint opens. Conversely, on a reduced irreducible scheme, two sections with zero product have disjoint nonvanishing basic opens, so one section vanishes.
