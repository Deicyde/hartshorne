# Generation by global sections

An `O_X`-module `F` is generated by global sections if and only if it is the
target of an epimorphism from a free module sheaf. Every quasi-coherent sheaf
on an affine scheme is globally generated, and for degree-one-generated
`X = Proj S`, the degree-one elements globally generate `O_X(1)`.
