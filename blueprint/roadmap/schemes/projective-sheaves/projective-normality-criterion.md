# The projective-normality criterion

Let `k` be algebraically closed. A closed subscheme `X ⊆ P_k^r` is
projectively normal if and only if `X` is normal and, for every `n ≥ 0`, the
restriction map

`Γ(P_k^r,O(n)) → Γ(X,O_X(n))`

is surjective.
