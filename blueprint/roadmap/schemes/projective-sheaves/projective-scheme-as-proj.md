# Projective schemes as Proj

A scheme $Y$ over $\operatorname{Spec} A$ is projective if and only if
$Y \cong \operatorname{Proj} S$ for a graded ring $S$ with $S_{0} = A$ that is finitely generated
by $S_{1}$ as an $A$-algebra.
