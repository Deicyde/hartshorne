# Twisting sheaves are invertible

For every graded ring $S$ and $X = \operatorname{Proj} S$, define
$\mathcal{O}_X(n) = \widetilde{S(n)}$ for $n\in\mathbb{Z}$, using Hartshorne's shift convention
$S(n)_d = S_{n+d}$. If $S$ is generated by $S_{1}$ as an $S_{0}$-algebra, then
every $\mathcal{O}_X(n)$ is an invertible sheaf.

On $D_{+}(f)$ for $f \in S_{1}$, multiplication by $f^n$ trivializes the twist; this
also fixes the sign convention for all later twist statements.
