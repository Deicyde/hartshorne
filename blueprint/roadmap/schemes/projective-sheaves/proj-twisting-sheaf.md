# Twisting sheaves are invertible

For every graded ring `S` and `X = Proj S`, define
`O_X(n) = S(n)~` for `n ∈ Z`, using Hartshorne's shift convention
`S(n)_d = S_{n+d}`. If `S` is generated by `S₁` as an `S₀`-algebra, then
every `O_X(n)` is an invertible sheaf.

On `D₊(f)` for `f ∈ S₁`, multiplication by `f^n` trivializes the twist; this
also fixes the sign convention for all later twist statements.
