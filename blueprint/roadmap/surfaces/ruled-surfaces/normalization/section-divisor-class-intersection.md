# Divisor class and intersection of a section

Fix normalized `E`, write `det(E)=O_C(eps)`, and let `C0` be a section with
`O_X(C0)=O_X(1)`. If a section `D` corresponds to a quotient
`E -> O_C(b)`, then

`deg(b)=C0.D`,

`D ~ C0 + (b-eps)f`,

and in particular `C0^2=deg(eps)=-e(X)`.
