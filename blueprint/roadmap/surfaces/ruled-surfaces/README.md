# Ruled surfaces

Hartshorne V.2 identifies geometrically ruled surfaces with rank-two
projective bundles over curves, normalizes the bundle, computes divisor and
intersection theory, classifies important rational and elliptic cases, and
determines ample cones. The fine roadmap has 48 project leaves.
