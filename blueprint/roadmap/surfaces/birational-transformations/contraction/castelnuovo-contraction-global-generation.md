# Global generation of the Castelnuovo contraction bundle

With the notation of the cohomology ladder, the invertible sheaf

`A=O_X(H+kY)`

is generated by global sections.  It is generated away from `Y` because `H`
is very ample and the canonical section of `kY` is nonzero there.  On `Y`,
one has `A|Y ~= O_Y`; the section `1` lifts globally because
`H^1(X,O_X(H+(k-1)Y))=0`.
