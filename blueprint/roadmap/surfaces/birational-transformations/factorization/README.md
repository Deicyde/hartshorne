# Factorization of birational maps of surfaces

This subchapter proves that a birational morphism of nonsingular projective
surfaces is a succession of point blowups whose number is the number of
contracted irreducible curves; the sequence itself need not be unique. It then eliminates
the indeterminacy of an arbitrary birational transformation by decreasing a
curve-genus defect. Consequently every birational transformation factors
into monoidal transformations and inverses. All statements are valid in
arbitrary characteristic.
