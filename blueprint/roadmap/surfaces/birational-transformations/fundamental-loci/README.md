# Fundamental loci of birational transformations

This subchapter packages the maximal domain and graph of a birational
transformation, then proves Hartshorne's Zariski-main variant for a
fundamental point. The graph total transform here is set-theoretic and must
not be confused with Cartier-divisor total transform. The results are valid
over an algebraically closed field of arbitrary characteristic.
