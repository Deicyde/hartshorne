# Canonical rings and Kodaira dimension

This subchapter defines the canonical section ring and Kodaira dimension for
nonsingular projective varieties over an algebraically closed field. It
packages the multiplicative birational comparison, the pluricanonical-map
interface, and the curve calculation. Hartshorne's historical comparison
with curve moduli and the open geography/moduli remarks are exposition and
are not roadmap claims.

10. [Kodaira dimension of a curve](curve-kodaira-dimension-trichotomy.md)

The pluricanonical characterization and every-value realization are retained
as explicit source blockers. No statement here concerns singular projective
varieties without an invertible canonical sheaf.
