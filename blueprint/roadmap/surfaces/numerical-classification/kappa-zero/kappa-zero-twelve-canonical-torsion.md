# Kodaira dimension zero and the twelfth canonical class

Assume `X` is a relatively minimal Chapter-V surface over an algebraically
closed field. Then

`kappa(X)=0` if and only if `12K_X~0`.

The right side means linear triviality of the twelfth canonical divisor; it
is not the empty-linear-system condition occurring for `kappa=-1`.

This node is not ready.  The easy direction follows from periodic nonzero
pieces of the canonical ring, but the converse is a quoted torsion theorem
from the classification of minimal surfaces.  An exact proof-level source
must be adopted.
