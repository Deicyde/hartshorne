# The twelfth plurigenus detects Kodaira dimension minus one

For a Chapter-V surface `X`,

`kappa(X)=-1` if and only if `P_12(X)=0`,

where

`P_12(X)=dim_k H^0(X,O_X(12K_X))`.

Equivalently, the complete linear system `|12K_X|` is empty.  This is not the
assertion that it is a nonempty system of projective dimension zero.

This node is not ready.  The implication from one fixed empty
pluricanonical system to the vanishing of every positive canonical-ring piece
is a quoted surface-classification theorem.  Hartshorne provides no proof,
and an exact arbitrary-characteristic passage must be adopted from the cited
classification sources.
