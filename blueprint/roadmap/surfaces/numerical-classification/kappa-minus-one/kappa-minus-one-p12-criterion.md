# The twelfth plurigenus detects Kodaira dimension minus one

For a Chapter-V surface $X$,

$\kappa (X)=-1$ if and only if $P_{12}(X)=0$,

where

$P_{12}(X)=\dim _k H^0(X,\mathcal{O}_X(12K_X))$.

Equivalently, the complete linear system $|12K_X|$ is empty.  This is not the
assertion that it is a nonempty system of projective dimension zero.
