# Assigned and unassigned base points of a linear system

For a complete system `|D|` on a surface and assigned points
`P_1,...,P_r`, define `|D-P_1-...-P_r|` as the subsystem of divisors passing
through them. Allow the points to lie on successive point blowups and allow
assigned multiplicities. A base point remaining on the corresponding
upstairs system is an unassigned base point.

If assigned points directly proximate to `P` have total multiplicity `s`, require
the multiplicity assigned at `P` to be at least `s`. This proximity
condition is part of the representation of iterated assigned-point data.
