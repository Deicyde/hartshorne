# Resolve the irreducible components first

For a reduced curve with finitely many irreducible components on a smooth
surface, a finite sequence of point blowups makes the strict transform of
every original component nonsingular. Every exceptional component introduced
along the way is already nonsingular.

## Depends on

- [Resolution of an irreducible curve on a surface](../strict-transforms/irreducible-curve-resolution.md)
- [The exceptional curve is a projective line](../foundations/exceptional-curve-projective-line.md)

## Proof depends on

- Resolve the components successively. Blowing up a point on a previously
  smooth curve leaves its strict transform isomorphic to that curve.
