# Monoidal transformations and curve resolution

Hartshorne V.3 studies blowing up a point on a smooth surface, exceptional
intersection and canonical formulas, cohomological invariants, strict
transforms and multiplicities, and embedded resolution of curves. The fine
roadmap has 32 project leaves.
