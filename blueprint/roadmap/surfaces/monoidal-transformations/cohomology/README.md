# Cohomology of a point blowup

This subchapter computes the infinitesimal neighborhoods of the exceptional
curve and applies formal functions to show that a monoidal transformation
preserves structure-sheaf cohomology. Consequently the arithmetic genus,
geometric genus, and irregularity are unchanged. The arguments are valid in
arbitrary characteristic.
