# Mumford's strictly-nef square-zero counterexample

There is a smooth projective surface $X$ and a divisor $D$ such that

$D\cdot C >0$

for every irreducible curve $C$, but $D^2=0$. Hence $D$ is not ample despite
being strictly nef.
