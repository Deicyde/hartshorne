# Standard intersection forms and adjunction

This subchapter computes the elementary intersection forms of projective
space and a smooth quadric, defines the canonical self-intersection, and
derives the adjunction genus formulas in Hartshorne V.1. All statements are
valid over an algebraically closed field in arbitrary characteristic.
