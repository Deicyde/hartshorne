# Valuation-space topology

For a one-dimensional function field `K/k`, this subchapter defines the
cofinite topology on `C_K` separately from the geometric theorem that `C_K` is
infinite.  The split keeps the unconditional topology construction independent
of the algebraic-closedness, finite-type, and transcendence-degree hypotheses
used to prove infinitude and irreducibility.
