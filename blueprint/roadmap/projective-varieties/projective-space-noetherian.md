# Projective space is a Noetherian space

`ℙⁿ` with the Zariski topology is a Noetherian topological space, so every
algebraic set in `ℙⁿ` is uniquely a finite union of irreducible algebraic sets
none of which contains another (Exercise 2.5).

Either route works: repeat the §1 argument with `J` in place of `I`, or deduce
it from the affine charts, since a space covered by finitely many Noetherian
open subspaces is Noetherian. The second is shorter given the chart
homeomorphism, and reuses the affine instance directly.

The uniqueness half is the decomposition theorem from §1, which applies to any
Noetherian space and needs no reproving here.
