# Projective space

Projective $n$-space $\mathbb{P} ^{n}$ over $k$ is the set of equivalence classes of
$(n+1)$-tuples $(a_{0},\ldots ,a_{n}) \in k^{n+1} \setminus \{0\}$ under $(a_{0},\ldots ,a_{n}) \sim (\lambda a_{0},\ldots ,\lambda a_{n})$ for
$\lambda \in k^\times$. A representative tuple is a set of *homogeneous coordinates* for the
point.
