# Sheaf Ext

For `O_X`-modules `F,G`, define the `O_X`-module

`𝓔xt^n_X(F,G) = R^n 𝓗om_X(F,-)(G)`.

For an injective resolution `G ⟶ I•`, identify it naturally with the
degree-`n` cohomology sheaf of `𝓗om_X(F,I•)`. This is a sheaf-valued derived
functor, not the global Ext group and not an assumed internal `R𝓗om` object.
