# Ext groups and sheaves

Hartshorne III.6 develops global Ext groups and sheaf Ext, then relates their
local and projective descriptions. The homological-dimension results prepare
for Serre duality in the next section.

The roadmap keeps global Ext groups, sheaf Ext objects, and derived Hom
models distinct. Their comparisons are explicit statements, so the reader can
follow which construction each result uses.
