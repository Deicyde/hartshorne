# Applications of formal functions

This chapter covers Hartshorne III.11, Corollaries 11.2–11.5, together with
the later-used Exercises 11.2, 11.3, and 11.8. The statements retain
Hartshorne's projective and Noetherian hypotheses. In particular, the article
labelled Zariski's Main Theorem is Hartshorne's connected-fibre theorem, not
the modern quasi-finite factorization theorem.
