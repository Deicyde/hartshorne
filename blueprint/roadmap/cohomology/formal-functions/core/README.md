# The theorem on formal functions

This subchapter constructs the infinitesimal fibres and natural comparison
map in Hartshorne III.11, isolates the projective-twist and Artin–Rees inputs,
and proves the theorem on formal functions. Natural-number stage `n` means
reduction modulo the `(n+1)`st power, so stage zero is Hartshorne's first
infinitesimal fibre.

Read the leaves in this order:

1. [Infinitesimal fibres](infinitesimal-fibers.md)
2. [The formal-functions comparison map](formal-functions-comparison-map.md)
3. [Formal functions for projective twists](formal-functions-projective-twist-case.md)
4. [The Artin–Rees kernel system is pro-zero](artin-rees-pro-zero-kernel.md)
5. [The theorem on formal functions](theorem-on-formal-functions.md)
6. [Faithfulness of maximal-adic completion on finite modules](maximal-adic-completion-faithful-finite.md)

The comparison-map representation is not ready because it depends on the
existing unresolved higher-direct-image base-change map. The other leaves
have fixed statements and become blocked only through ordinary DAG edges.
