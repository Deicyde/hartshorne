# Cohomology on projective space

This chapter follows Hartshorne III.5, Theorems 5.1–5.3. It computes all
twist cohomology, proves coherent finiteness and Serre vanishing, and derives
the cohomological ampleness criterion.

5. [Intermediate twist cohomology vanishes](projective-space-intermediate-twist-vanishing.md)
