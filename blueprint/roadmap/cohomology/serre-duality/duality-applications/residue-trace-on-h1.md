# The residue trace on first cohomology

The sum of local residues on differential principal parts vanishes on the
image of `Ω_(K/k)` and therefore descends to a `k`-linear map

`tr_res : H¹(X,Ω_X) →ₗ k`.

The node remains not ready with the global residue theorem on which the
descent depends.

## Depends on

- [The global residue theorem](curve-global-residue-theorem.md)
- [The differential principal-parts resolution](curve-differential-principal-parts-resolution.md)

## Proof depends on

- Compatibility of the direct-sum residue functional with the cokernel model
  for `H¹(X,Ω_X)`.
