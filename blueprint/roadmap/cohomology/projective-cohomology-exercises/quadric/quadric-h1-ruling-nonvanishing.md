# Ruling-direction quadric H¹ nonvanishing

For the split nonsingular quadric $Q$, if $a\le -2$, then
$H^{1}(Q,\mathcal{O}_Q(a,0))\ne 0$.

- [The class group of a nonsingular quadric surface](../../../schemes/divisors/weil-divisors/quadric-surface-class-group.md)

## Proof depends on

- Restriction to a union of ruling lines and the resulting cohomology exact
  sequence.

Hartshorne supplies only the exercise instruction; the dimension calculation
must be specified before this root is ready.
