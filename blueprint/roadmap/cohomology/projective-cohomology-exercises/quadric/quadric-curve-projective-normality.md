# Projective normality on a quadric

Let `k` be algebraically closed and let `Y⊆Q⊆P³_k` be an irreducible
nonsingular curve of type `(a,b)` with `a,b>0`. Then `Y` is projectively
normal in `P³` if and only if `|a-b|≤1`.
