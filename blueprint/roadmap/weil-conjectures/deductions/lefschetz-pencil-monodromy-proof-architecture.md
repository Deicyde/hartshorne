# Lefschetz-pencil and monodromy proof architecture

Deligne's proof of purity uses Lefschetz pencils, the geometry of singular
fibres, and the monodromy action on ℓ-adic cohomology. This node records the
proof architecture needed to connect the SGA7 monodromy package to the weight
theorem; it is not itself a substitute for Deligne's theorem.
