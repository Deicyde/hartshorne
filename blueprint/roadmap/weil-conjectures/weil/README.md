# The modern Weil theorem package

For smooth projective geometrically connected varieties over finite fields,
this subchapter records rationality, the cohomological polynomial
factorization, functional equation, Deligne weights, and Betti consequences.
Hartshorne's historical word “conjectures” is retained only in prose: these
are modern theorems. Appendix C §4 supplies the cohomological deductions and
does not duplicate these final theorem nodes.
