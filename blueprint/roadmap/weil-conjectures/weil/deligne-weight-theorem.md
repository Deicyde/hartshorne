# Deligne's weight theorem

For each Weil polynomial,

$P_i(t)=\prod _j (1-\alpha _{(i,j)}\cdot t)$,

where every $\alpha _{(i,j)}$ is an algebraic integer and every complex embedding
has absolute value

$|\alpha _{(i,j)}|=q^{i/2}$.
