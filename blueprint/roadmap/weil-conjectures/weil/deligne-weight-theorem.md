# Deligne's weight theorem

For each Weil polynomial,

`P_i(t)=product_j (1-alpha_(i,j)*t)`,

where every `alpha_(i,j)` is an algebraic integer and every complex embedding
has absolute value

`|alpha_(i,j)|=q^(i/2)`.
