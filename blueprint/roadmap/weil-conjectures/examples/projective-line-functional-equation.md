# The projective-line zeta function satisfies its functional equation

As rational functions,

`Z(P^1,1/(q*t))=q*t^2*Z(P^1,t)`.

## Depends on

- [The zeta function of the projective line](../zeta/projective-line-zeta-function.md)
- [The diagonal Euler number of the projective line](projective-line-diagonal-euler-number.md)

## Proof depends on

- Substitute `1/(q*t)` into the explicit rational function and simplify.
