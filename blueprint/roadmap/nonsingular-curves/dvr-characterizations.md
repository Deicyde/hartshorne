# Characterizations of discrete valuation rings

Let $A$ be a Noetherian local domain of Krull dimension one, with maximal
ideal $\mathfrak{m}$. Then the following conditions are equivalent:

1. $A$ is a discrete valuation ring;
2. $A$ is integrally closed;
3. $A$ is a regular local ring;
4. $\mathfrak{m}$ is principal.

This is Theorem 6.2A. It provides the algebraic criterion used to identify
the local ring of a nonsingular curve point as a discrete valuation ring.
