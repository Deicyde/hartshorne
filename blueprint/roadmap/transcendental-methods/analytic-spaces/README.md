# Complex analytic spaces and coherent analytic sheaves

This subchapter fixes the possibly nonreduced Grauert analytic-space
interface required by Appendix B. Complex points with a topology and smooth
complex manifolds are insufficient representations: quotient holomorphic
structure sheaves, nilpotents, locally ringed-space gluing, and coherent
analytic modules are retained.
