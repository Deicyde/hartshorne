# Transcendental methods

Hartshorne Appendix B connects algebraic geometry with complex analysis
through analytification, GAGA, and Chow's theorem. It also presents
algebraicity criteria for compact complex manifolds, Kähler and Hodge
geometry, and the exponential-sequence description of Picard varieties.
