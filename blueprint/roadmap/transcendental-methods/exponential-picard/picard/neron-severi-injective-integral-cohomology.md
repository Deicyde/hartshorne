# The Néron–Severi group embeds in integral cohomology

For a projective complex variety, the topological first Chern class descends
to an injective homomorphism

`NS(X) -> H^2(X^h,Z)`.

## Depends on

- [Algebraic equivalence preserves the topological class](algebraic-equivalence-topological-class.md)
- [The cohomological quotient description of Pic0](pic-zero-cohomology-quotient.md)

## Proof depends on

- The kernel of the topological Chern class on `Pic(X)` is exactly the
  identity component `Pic^0(X)`, whose divisor classes are algebraically
  trivial.
