# The cohomological quotient description of Pic0

For a smooth projective complex variety, exactness of the exponential
sequence identifies

`Pic^0(X) ~= H^1(X,O_X)/image(H^1(X^h,Z))`.

Here `Pic^0` means algebraically trivial divisors modulo linear equivalence;
the equality with the kernel of `c_1^top` uses the algebraic/topological
comparison.

This node is not ready: the current algebraic-equivalence theorem gives only
`Pic^0 subset ker(c_1^top)`. The converse identification requires an exact
Picard-functor/Picard-variety theorem.
