# The cohomological quotient description of Pic0

For a smooth projective complex variety, exactness of the exponential
sequence identifies

$\operatorname{Pic} ^0(X) \simeq H^1(X,\mathcal{O}_X)/\operatorname{image} (H^1(X^h,\mathbb{Z}))$.

Here $\operatorname{Pic} ^0$ means algebraically trivial divisors modulo linear equivalence;
the equality with the kernel of $c_1^\top$ uses the algebraic/topological
comparison.
