# Basic algebraic–analytic comparison properties

For finite-type complex schemes, analytification compares separation,
connectedness, reducedness, smoothness, and properness with their analytic
counterparts. Hartshorne cites Serre rather than proving these assertions.
The final leaf records Serre's nonproper ruled-surface counterexample.
