# Separably generated field extensions

Three results Hartshorne quotes without proof, used only to prove
[Proposition 4.9](birational-hypersurface.md):

- **Theorem 4.6A** (primitive element). A finite separable extension `L/K` is
  generated by one element; and if `K` is infinite, a generator can be taken to
  be a `K`-linear combination of any given set of generators.
- **Definition.** `K/k` is *separably generated* if it has a transcendence base
  `{xᵢ}` — a *separating transcendence base* — with `K` separably algebraic over
  `k({xᵢ})`.
- **Theorem 4.7A.** If `K/k` is finitely generated and separably generated, then
  any generating set contains a separating transcendence base.
- **Theorem 4.8A.** If `k` is perfect, in particular if `k` is algebraically
  closed, then every finitely generated extension `K/k` is separably generated.

## What the pinned Mathlib has

Checked against the pinned checkout:

- **4.6A** is `Field.exists_primitive_element`, under
  `[FiniteDimensional F E] [Algebra.IsSeparable F E]`. The refinement about
  linear combinations of given generators is not stated separately upstream and
  is not needed below.
- **4.8A** is `exists_isTranscendenceBasis_and_isSeparable_of_perfectField`,
  under `[PerfectField k] [Algebra.EssFiniteType k K]`. It returns a finite
  `s : Finset K` that is a transcendence basis with `K` separable over
  `k(s)` — that is, a separating transcendence base, so it delivers 4.8A and
  the existence content of 4.7A in one statement. `PerfectField k` is an
  instance for an algebraically closed `k`, which is the standing hypothesis.
- **4.7A** in Hartshorne's exact form, that a separating transcendence base can
  be found *inside a prescribed generating set*, is not matched. Proposition 4.9
  does not use that refinement: it needs a separating transcendence base to
  exist, not to sit inside a chosen generating set. So the gap is recorded and
  not closed.

This node therefore claims nothing beyond wrapping the two upstream results in
the shape Proposition 4.9 consumes: a finite separating transcendence base
`x₁,…,x_r` for `K/k` with `r = trdeg_k K`, and a single `y` with
`K = k(x₁,…,x_r, y)`.
