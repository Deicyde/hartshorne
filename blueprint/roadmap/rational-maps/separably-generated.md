# Separably generated field extensions

Three results Hartshorne quotes without proof, used only to prove
[Proposition 4.9](birational-hypersurface.md):

- **Theorem 4.6A** (primitive element). A finite separable extension $L/K$ is
  generated by one element; and if $K$ is infinite, a generator can be taken to
  be a $K$-linear combination of any given set of generators.
- **Definition.** $K/k$ is *separably generated* if it has a transcendence base
  $\{x_{i}\}$ — a *separating transcendence base* — with $K$ separably algebraic over
  $k(\{x_{i}\})$.
- **Theorem 4.7A.** If $K/k$ is finitely generated and separably generated, then
  any generating set contains a separating transcendence base.
- **Theorem 4.8A.** If $k$ is perfect, in particular if $k$ is algebraically
  closed, then every finitely generated extension $K/k$ is separably generated.

The construction used in [Proposition I.4.9](birational-hypersurface.md) chooses a finite separating
transcendence basis $x_1,\ldots,x_r$ for $K/k$, where
$r=\operatorname{trdeg}_k K$, and then a primitive element $y$ with
$K=k(x_1,\ldots,x_r,y)$. It does not require the separating basis to lie
in a prescribed generating set.
