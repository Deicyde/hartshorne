# The Kleiman–Laksov gonality threshold

Let `g` and `d` be positive integers.

- If `2*d >= g+2`, every genus-`g` curve has a `g^1_d`.
- If `2*d < g+2`, there exist genus-`g` curves having no `g^1_d`.
