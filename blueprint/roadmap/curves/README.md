# Curves

Hartshorne Chapter IV studies complete nonsingular curves over an
algebraically closed field. The current fine scope covers §§IV.1–2, printed
pp.294–306: 47 Chapter IV leaves, of which Lüroth's theorem is exact pinned
Mathlib and 46 are project targets. Three additional project prerequisites
reactivate Exercises I.5.4, I.7.3, and II.6.4.
