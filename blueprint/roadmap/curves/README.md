# Curves

Hartshorne Chapter IV studies complete nonsingular curves over an
algebraically closed field. The current fine scope covers §§IV.1–3, printed
pp.294–316: 77 Chapter IV leaves, of which Lüroth's theorem is exact pinned
Mathlib and 76 are project targets. Five additional project prerequisites
reactivate Exercises I.3.14(a), I.5.4, I.5.6(b), I.7.3, and II.6.4.
