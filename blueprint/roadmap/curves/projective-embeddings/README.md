# Projective embeddings and nodal plane models

Hartshorne IV.3 develops numerical criteria for generated and very ample
divisors, projects curves into `P^3`, classifies strange curves, and proves
that every curve has a birational plane model with only nodes. The section
contributes 30 project targets; two additional Chapter I prerequisites supply
projection from a point and the ordinary-node local model.
