# Linear series and projection of curves

This subchapter covers Hartshorne IV.3, printed pp.307–310, through the local
criterion for a nodal plane projection. All curves are integral proper regular
one-dimensional schemes over an algebraically closed field. The statements
are valid in arbitrary characteristic.
