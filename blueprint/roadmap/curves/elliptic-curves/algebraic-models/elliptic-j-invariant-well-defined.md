# The j-invariant is intrinsic

For a pointed elliptic curve in characteristic different from two, define

`j(lambda)=2^8*(lambda^2-lambda+1)^3/(lambda^2*(lambda-1)^2)`

from any Legendre model. The resulting element of `k` is independent of the
base point, degree-two map, ordering of branch points, and normalized
Legendre parameter. It therefore depends only on the abstract elliptic curve.

## Proof depends on

- The displayed rational function is invariant under generators
  `lambda |-> 1/lambda` and `lambda |-> 1-lambda` of the `S_3` action.
