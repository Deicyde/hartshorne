# The Fermat and Tate rational-point examples

The Fermat cubic `x^3+y^3=z^3` has exactly three rational points, which form
`Z/3Z` after choosing any one as origin. For the curve
`y^2+y=x^3-x`, Tate's stated computation identifies the rational-point group
as infinite cyclic generated by `(0,0)`.
