# The Gruson–Peskine proof of Halphen's existence classification

Adopt a precise modern statement and proof of Halphen's general
classification of the pairs `(d,g)` for which a nonsingular degree-`d`,
genus-`g` curve exists in `P^3`.

This is a source root rather than a guessed numerical theorem. Hartshorne
only says that Halphen stated the classification and that Gruson–Peskine
later supplied a correct proof; he does not state the full criterion here.
The node remains not ready until an exact proof-level passage, hypotheses,
and characteristic boundary are adopted.
