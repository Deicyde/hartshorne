# Lüroth's theorem

Let $k$ be a field and let $L$ be an intermediate field between $k$ and the
rational function field $k(t)$. If $L \ne k$, then there is a $k$-algebra
isomorphism

$k(t)\simeq L$.

Equivalently, $L=k(u)$ for a transcendental element $u$. Hartshorne derives
the result over an algebraically closed field from genus monotonicity. The
field-theoretic statement given here holds over an arbitrary field.
