# A hypersurface in affine space drops the transcendence degree by one

For `f ∈ k[y₁,…,y_d]` irreducible, `k[y₁,…,y_d]/(f)` is a domain whose fraction
field has transcendence degree `d − 1` over `k`.

This is the base computation behind
[the dimension formula](dim-formula-catenary.md), and it is where the number
`1` in "height one" turns into the number `1` in "transcendence degree drops by
one".

The argument is elementary once said correctly. Some variable `y_i` occurs in
`f`; then the class of `y_i` in the quotient is algebraic over the subfield
generated by the others, because `f` itself is a nonzero polynomial relation
satisfied by it. The remaining `d − 1` variables stay algebraically independent,
since a relation among them would lie in `(f)` and be divisible by `f`, which
involves `y_i`. So the quotient is algebraic over a purely transcendental
extension of degree `d − 1`.

Not to be confused with [the hypersurface dimension](hypersurface-dimension.md)
node, which is Hartshorne's Proposition 1.13 and is a *consequence* of the
dimension formula. This one is an input to it, and is about a polynomial ring
rather than an arbitrary affine variety.
