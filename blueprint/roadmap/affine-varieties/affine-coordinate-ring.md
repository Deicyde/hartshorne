# The affine coordinate ring

For an affine algebraic set $Y\subseteq\mathbb{A}^n$ over $k$, the
*affine coordinate ring* is

$$A(Y)=k[x_1,\ldots,x_n]/I(Y).$$

When $Y$ is a variety, $I(Y)$ is prime, so $A(Y)$ is a finitely generated
$k$-algebra and an integral domain.

[Hartshorne's converse in Remark I.1.4.6](coordinate-ring-realization.md)
states that every finitely generated $k$-algebra domain arises in this way.
