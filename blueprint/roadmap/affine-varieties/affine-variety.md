# Affine and quasi-affine varieties

A nonempty subset $Y$ of a topological space is *irreducible* when it is not
the union of two proper subsets each closed in $Y$. An *affine variety* is
an irreducible closed subset of $\mathbb{A}^n$ with the induced topology.
A *quasi-affine variety* is a nonempty open subset of an affine variety.

Hartshorne's varieties are always irreducible. Thus the zero set of a
reducible polynomial is an algebraic set and need not be a variety. The
empty set is excluded from the definition of an irreducible variety.
