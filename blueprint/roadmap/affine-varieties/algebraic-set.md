# Algebraic sets

Fix an algebraically closed field $k$ and let $A=k[x_1,\ldots,x_n]$.
For a subset $T\subseteq A$, its zero set is

$$Z(T)=\{P\in\mathbb{A}^n: f(P)=0\text{ for every }f\in T\}.$$

A subset $Y\subseteq\mathbb{A}^n$ is an *algebraic set* if $Y=Z(T)$
for some $T$. The zero set depends only on the ideal generated by $T$.
Since $A$ is Noetherian, every algebraic set is the common zero set of a
finite family of polynomials.
