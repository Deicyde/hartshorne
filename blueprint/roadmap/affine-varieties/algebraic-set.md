# Algebraic sets

Fix an algebraically closed field `k` and let `A = k[x₁,…,xₙ]`. Reading a
polynomial `f ∈ A` as a function on affine `n`-space `𝔸ⁿ = kⁿ`, the zero set of a
subset `T ⊆ A` is

`Z(T) = { P ∈ 𝔸ⁿ : f(P) = 0 for all f ∈ T }`.

A subset `Y ⊆ 𝔸ⁿ` is an *algebraic set* when `Y = Z(T)` for some `T`. Two
immediate reductions belong here because everything later uses them: `Z(T)`
depends only on the ideal generated by `T`, and since `A` is Noetherian every
algebraic set is the zero set of a finite family.

Mathlib already has this construction as `MvPolynomial.zeroLocus` for a subring
`k` of a field `K`, indexed by an arbitrary `σ` rather than `Fin n`. The node
should reuse it rather than introduce a parallel definition; what it adds is the
`k = K` specialisation Hartshorne works in and the reduction to ideals.
