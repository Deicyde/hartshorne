# Coverage contract

**Status: scope not yet defined.** The repository infrastructure is ready, but
no source material has been scoped and no results have been chosen. Nothing here
should be read as a claim that any part of Hartshorne is formalized.

## In scope

Not yet decided. The source text is Robin Hartshorne, *Algebraic Geometry*
(Springer, Graduate Texts in Mathematics 52, 1977). The chapters, sections, and
individual results this project intends to formalize will be recorded here
before roadmap work begins.

## Out of scope

Not yet decided. Material that Mathlib already covers, and material deliberately
excluded, will be listed here with the reason.

## Done means

Not yet decided. A chapter will count as finished only when every result listed
under **In scope** for it has a Lean statement and proof that compile with no
`sorry` and no added axioms beyond Lean's three.
