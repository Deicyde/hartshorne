# Smooth projective geometrically connected varieties over a finite field

## Lean (module `Hartshorne.Weil.GeometricallyConnectedSmoothProjective`)

- `Hartshorne.IsSmoothProjectiveGeometricallyConnected k f n` for a finite field `k`
  (`[Field k] [Finite k]`, as in `Hartshorne.pointCountSequence`) and `f : X ⟶ Spec k`, a
  `Prop`-valued structure with fields
  - `smoothOfRelativeDimension : SmoothOfRelativeDimension n f` (Mathlib), which over a field
    encodes "smooth of pure dimension `n`";
  - `projective : Hartshorne.Projective f`;
  - `connectedSpace_baseExtension`: `ConnectedSpace` of `Hartshorne.baseExtension f` along
    `Spec (AlgebraicClosure k) ⟶ Spec k`. Connectedness includes nonemptiness, so the empty
    scheme (smooth of every relative dimension) is excluded.
- Mathlib's `AlgebraicGeometry.GeometricallyConnected` (connected after every field base
  change) is not used: the article asks only for the base change to an algebraic closure.
