# Morphisms from generated invertible sheaves

## Status: not started in Lean; does not close within a 1.5 h attempt

No Lean has been written for this node. The statement is Hartshorne II.7.1 in both directions,
with uniqueness and the pullback data. No single missing node blocks it, but it is a large
development: an estimated one to two days, mostly for the converse.

## Supporting implementation references

  `Proj.fromOfGlobalSections_morphismRestrict` (Mathlib). These build `X ⟶ Proj 𝒜` from a ring map
  `𝒜 →+* Γ(X, ⊤)` whose image of the irrelevant ideal generates the unit ideal. They take global

## Route

1. **Coordinate sections.** Define `x_i ∈ Γ(ℙⁿ_Y, 𝒪(1))` as the pullback, along
   `pullback.fst : ℙⁿ_Y ⟶ ℙⁿ_ℤ`, of `degreeOneSection (X i)`. Show that they generate
   `projectiveSpaceTwistingSheaf n Y 1`, using the stalks of the pullback.
2. **Forward direction.** For `φ : X ⟶ ℙⁿ_A` over `A`, `L = φ^* 𝒪(1)` is invertible, and the
   `φ^* x_i` generate it. This uses pullback of generating sections, via `pullbackStalkIso`.
3. **Converse.** Let `s_0, …, s_n` generate an invertible `L`. On `X_{s_i}`, `s_i` trivializes `L`,
   so `s_j/s_i ∈ Γ(X_{s_i}, 𝒪)`. This gives `X_{s_i} ⟶ D₊(x_i) ≅ Spec A[x_j/x_i]`. These maps agree
   on overlaps, so glue them with `Scheme.Cover.glueMorphisms`, or apply `fromOfGlobalSections`
   chartwise.
4. **Pullback data and uniqueness.** Build `φ^* 𝒪(1) ≅ L` sending `φ^* x_i ↦ s_i` chartwise, by
   comparing frames as in `IsLocalFrame.app_bijective_of_map`. Uniqueness holds because a
   morphism into `ℙⁿ_A` is determined on the cover `φ⁻¹ D₊(x_i) = X_{s_i}` by the ratios
   `s_j/s_i`.
