# Projective schemes as Proj

## Lean statement

`Hartshorne.projective_iff_exists_iso_proj` (module
`Hartshorne.Scheme.ProjectiveSchemeAsProj`). For `f : Y ⟶ Spec A`,
`Projective f` holds if and only if there are a ring `S`, a grading
`𝒜 : ℕ → AddSubgroup S` with `GradedRing 𝒜`, a ring isomorphism `φ : A ≃+* 𝒜 0`
(the identification `S₀ = A`), a finite set of degree-one elements generating `S`
as an `𝒜 0`-algebra, and an isomorphism `e : Y ≅ Proj 𝒜` with
`e.hom ≫ Proj.toSpecZero 𝒜 ≫ Spec.map φ = f` (so the isomorphism is over `Spec A`).
The `A`-algebra structure of `S` is the one through `φ`, which is why generation is
stated over `𝒜 0`, in the same form as `projective_projToSpecZero_of_degreeOne_generators`.

## Proof route

Forward: `Projective f` gives a closed immersion `i` into `ℙʳ_{Spec A}`
(`projectiveSpaceOverScheme`). Composing with the inverse of
`projectiveSpaceOverSpecIso A r (Equiv.refl _)` gives a closed immersion into
`Proj A[x₀, …, xᵣ]`, to which Cor. 5.16(a)
(`ProjectiveClosedSubscheme.exists_iso_projQuotientι_gammaStarIdeal`) applies with
`I = gammaStarIdeal`. The degree-zero part of `I = Γ_*(I_Y) ∩ S` is
`Γ(ℙʳ_A, I_Y) ∩ A`, which can be nonzero (for instance when `Y` lies over a proper
closed subscheme of `Spec A`), and then `(S/I)₀ = A/I₀ ≠ A`. The book's proof passes
over this. The Lean replaces `I` by its truncation `I_{≥1}`
(`homogeneousTruncation _ I 1`), which defines the same closed subscheme
(`exists_iso_projQuotientι_homogeneousTruncation`, Ex. II.3.12(b)); then
`A → (S/I_{≥1})₀` is bijective (private `degreeZeroHom_bijective`) and the images of
the `xⱼ` generate (private `adjoin_mk_X_eq_top`). The compatibility over `Spec A`
uses `projToProjectiveSpaceOverSpec_projection` and `projMap_toSpecZero`.

Backward: `projective_projToSpecZero_of_degreeOne_generators` plus
`MorphismProperty.RespectsIso` for `Projective`.
