# Tensor products of very ample sheaves

## Status

Not formalized. One prerequisite is missing (Roadmap return below); no Lean was committed.

## Route

Start from very ample data `i : X ⟶ ℙʳ_Y` with `i^*𝒪(1) ≅ L` and `j : X ⟶ ℙˢ_Y` with
`j^*𝒪(1) ≅ M` (`Hartshorne.IsVeryAmpleRelative`, which requires quasi-compact immersions).

1. Build `(i, j) : X ⟶ ℙʳ_Y ×_Y ℙˢ_Y` (`Hartshorne.relativeSegreSource`) as a quasi-compact
   immersion by factoring it as follows.
   - The graph `X ⟶ X ×_Y ℙˢ_Y` of `j` is a base change of the diagonal of
     `ℙˢ_Y ⟶ Y`. That diagonal is a closed immersion, since `ℙˢ_Y ⟶ Y` is separated
     (`projectiveSpaceOverSchemeProjection_isProper`).
   - Follow it by `i ×_Y ℙˢ_Y`, a base change of `i`.
   - Quasi-compact immersions are stable under base change and composition.
   - Do not route through the diagonal of `X` over `Y`: it need not be quasi-compact.
2. Compose with the relative Segre closed immersion `Hartshorne.relativeSegre r s Y`. The result
   is a quasi-compact immersion over `Y`, by `relativeSegre_projection`.
3. Compute `(σ ∘ (i, j))^*𝒪(1) ≅ i^*𝒪(1) ⊗ j^*𝒪(1) ≅ L ⊗ M` using
   `Hartshorne.pullbackTensorIso` (PicardPullback), the pseudofunctoriality of pullback, and the
   missing identity `σ^*𝒪(1) ≅ p₁^*𝒪(1) ⊗ p₂^*𝒪(1)`.

## Missing prerequisite (Roadmap return)

Step 3 needs `σ^*𝒪_{ℙ^{rs+r+s}_Y}(1) ≅ p₁^*𝒪_{ℙʳ_Y}(1) ⊗ p₂^*𝒪_{ℙˢ_Y}(1)` for the Segre
morphism `σ`. Neither the relative-segre-closed-immersion article (its `lean:` is
`relativeSegre`, `relativeSegre_spec`) nor proj-twist-compatibility states it, and the project
has no such Lean.

A route: over `ℤ`, on the chart `D₊(z_{ij})`, `σ` sends `z_{kl}/z_{ij}` to
`(x_k/x_i)(y_l/y_j)` (`segreMorphismInt_appLE_chartRatio`). So both sides are trivialized on
`D₊(x_i) × D₊(y_j)` with the same transition functions. Glue a frame isomorphism as in the Pic
computations, then base change to `Y`.

Add this identity to the Segre article, or make it a separate node that very-ample-tensor-product
depends on.
