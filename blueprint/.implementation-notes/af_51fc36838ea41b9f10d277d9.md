# Differentials on affine schemes

## Revision: Example II.8.12.1 over any base scheme

The corollary was restated from affine $n$-space over $\operatorname{Spec} A$ to
$\mathbf{A}^n_Y$ over an arbitrary scheme $Y$, as Hartshorne states Example 8.12.1. The
article is retracted until Lean for the general statement exists; the recorded
declarations stay in `lean:` and remain correct (the affine statements are the special case
$Y = \operatorname{Spec} A$).

To re-record, a Formalize pass must add a new theorem (keeping the existing ones) stating, for
`Y : Scheme.{u}` and an index type `σ : Type u`, that

```
IsIso ((Scheme.relativeDifferentials (𝔸(σ; Y) ↘ Y)).freeHomEquiv.symm
  (fun i => Scheme.relativeDifferentialsDSection _ (AffineSpace.coord Y i)))
```

with a rank-`n` specialization at `σ = ULift (Fin n)`, and add them to `lean:`.

Planned route: check the isomorphism locally (`Hartshorne.Ringed.modules_isIso_of_locally_bijective`)
on the opens `j : Spec Γ(Y, V)[σ] ⟶ 𝔸(σ; Y)` given by `(AffineSpace.SpecIso σ _).inv ≫
AffineSpace.map σ hV.fromSpec` for affine opens `V` of `Y`; restricted along `j`, the map is
identified (via `Scheme.Modules.restrictFreeIso` and `RelDiffLocal.restrictIso`) with the
affine isomorphism `Scheme.relativeDifferentials_mvPolynomial_free`.

The locality isomorphism `RelDiffLocal.restrictIso` is proved in
