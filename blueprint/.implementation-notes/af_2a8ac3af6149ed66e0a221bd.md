# Diagonal conormal comparison

Pinned Mathlib has the `IsImmersion` instance for a diagonal and the canonical
`liftCoborder` factorization into a closed immersion followed by an open
immersion. It has `IdealSheafData` on affine opens, but no associated module
sheaf `J/J^2` for an arbitrary immersion and no comparison between such a
conormal sheaf and the sheafification of relative Kähler differentials. The
existing presheaf-differentials file explicitly leaves the general
different-site construction as a TODO.

Do not discharge the comparison by defining "diagonal conormal sheaf" to be
the relative differential sheaf: that would make the theorem tautological
without relating it to the diagonal ideal. First implement the conormal sheaf
of an immersion in `af_16b35b95a8072241ce2a54a1` and its neighbourhood-
independence theorem in `af_e270dcd9c883d0a770b48853`, then prove the
comparison with the universal differential sheaf.
