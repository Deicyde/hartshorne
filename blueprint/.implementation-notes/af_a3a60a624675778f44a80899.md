# Sheaf cohomology

## Status after the roadmap revision

The former blocker ("not ready until that derived comparison is specified
against Mathlib's two constructions") is resolved by the roadmap revision that
split the old article "Sheaf cohomology and the Ext model". This article now
holds only Hartshorne's definition `Hⁿ(X,-) := RⁿΓ(X,-)` (III.2, p. 207) and
the degree-zero identification `H⁰(X,F) ≅ Γ(X,F)`, which is what nearly all
downstream consumers use. The comparison with Mathlib's `Sheaf.H` (Ext from
the constant sheaf, compatible with connecting maps) is the separate bridged
article `sheaf-cohomology-ext-comparison` (af_20b90b5104320442f4732041).
No partial Lean progress was recorded for the old article.

## Lean plan

Universe: `X : TopCat.{u}`, sheaves `TopCat.Sheaf AddCommGrpCat.{u} X`, values
in `AddCommGrpCat.{u}`. No extra hypothesis is needed: `HasInjectiveResolutions`
comes from `IsGrothendieckAbelian.{u}` (instance in
`Mathlib/Topology/Sheaves/Abelian.lean`, via
`Mathlib/CategoryTheory/Abelian/GrothendieckCategory/EnoughInjectives.lean`).

Candidate declarations (new module, e.g. `Hartshorne/Cohomology/SheafCohomology.lean`):

- `Hartshorne.sheafCohomology (X : TopCat.{u}) (n : ℕ) :
  TopCat.Sheaf AddCommGrpCat.{u} X ⥤ AddCommGrpCat.{u} :=
  (sheafSectionsOver (X := X) ⊤).rightDerived n` (`Functor.rightDerived`,
  `Mathlib/CategoryTheory/Abelian/RightDerived.lean`). Make it an `abbrev`
  (or prove an `rfl` lemma) so that it agrees with the inline
  `(sheafSectionsOver ⊤).rightDerived n` already used by the formalized
  cohomology-with-supports, excision and Mayer–Vietoris files
  (`Hartshorne.cohomologyWithSupportsToCohomology`,
  `Hartshorne.cohomologyRestriction`, `Hartshorne.localizationδ`).
- `Hartshorne.sheafCohomologyZeroIso (X : TopCat.{u}) :
  sheafCohomology X 0 ≅ sheafSectionsOver (X := X) ⊤ :=
  Functor.rightDerivedZeroIsoSelf _` (needs
  `Hartshorne.sheafSectionsOver_preservesFiniteLimits`).

`Hartshorne.sheafSectionsOver` and its `PreservesFiniteLimits` instance live in
`Hartshorne/Cohomology/CohomologyWithSupports.lean`. Prefer moving them
unchanged (same names) into the new foundational module and importing it from
`CohomologyWithSupports`, rather than importing the heavy supports file. The
alternative global-sections functor `CategoryTheory.Sheaf.Γ`
(`Mathlib/CategoryTheory/Sites/GlobalSections.lean`, used by the project's
étale `torsionEtaleCohomology`) is isomorphic via `Sheaf.ΓNatIsoSheafSections`
with `Limits.isTerminalTop`; staying with evaluation at `⊤` keeps the existing
topological files definitionally compatible.

Connecting maps and the long exact sequence need no new declaration: they are
`Hartshorne.rightDerivedδ (sheafSectionsOver ⊤) hS n` and
`Hartshorne.rightDerived_exact₁/₂/₃`, `Hartshorne.rightDerived_mono_map_f`.
Vanishing on injectives is Mathlib's `Functor.isZero_rightDerived_obj_injective_succ`.
