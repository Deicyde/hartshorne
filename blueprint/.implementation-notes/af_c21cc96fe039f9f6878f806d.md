# Quasi-coherent flasque envelopes

## Prior implementation guidance

Work in progress on `frontier/w29l`, in
`src/Hartshorne/Cohomology/QuasicoherentFlasqueEnvelope.lean`. The module is not
imported by the library root yet. The committed file holds only compiled pieces:
`isFlasque_pushforward` and `sum_app_apply`. Work stopped because host load went
over 150.

Planned statement: for `[IsNoetherian X]` and `F : X.Modules` with
`[F.IsQuasicoherent]`, there are `G` and `ι : F ⟶ G` with `Mono ι`,
`TopCat.Presheaf.IsFlasque G.presheaf` and `G.IsQuasicoherent`.

Steps:

- Instances and existing results:
  - `X.Modules` does not infer `HasFiniteBiproducts`. Add
    `attribute [local instance] HasFiniteBiproducts.of_hasFiniteProducts`
    (not yet tested).
  - Flasque pushforward: `isFlasque_pushforward`, by
    `IsFlasque.epi (F := G.presheaf) ((Opens.map f.base).op.map i)`. It compiled.
- Finite direct sums: `isFlasque_biproduct`, not yet written; the following
  sketch was drafted but never compiled.
  - Lift each component `π_j s`, then take `t = ∑ ι_j (t_j)`.
  - Restriction commutes with `ι_j` (the `hnat` step).
  - The step left to finish: `∑ ι_j.app V (π_j.app V s) = s`. Use
    `sum_app_apply` with `biproduct.total` and `Hom.id_app`.
- Finite affine cover: `t : Finset X.affineOpens`, as in
  `exists_coherentNear_top` of `CoherentExtension`. For each `V ∈ t`:
  - `M := moduleSpecΓFunctor.obj (specRestriction F V)`.
  - `e : tilde M ≅ specRestriction F V`, which is `asIso fromTildeΓ`. Use
    `isQuasicoherent_iff_isIso_fromTildeΓ` and the Mathlib instance
    `isQuasicoherent_restrictFunctor`.
  - `I := Injective.under M`. `EnoughInjectives (ModuleCat Γ(X, V))` comes from
    `Mathlib.Algebra.Category.ModuleCat.EnoughInjectives`. Get
    `Module.injective_module_of_injective_object`.
  - `IsNoetherianRing Γ(X, V)` comes from `isNoetherianRing_affineOpen` or
    `IsLocallyNoetherian.component_noetherian`.
  - `α := e.inv ≫ tilde.map (Injective.ι M)`. It is mono by
    `affineTilde_map_mono`.
  - `φ_V := (Scheme.Modules.restrictAdjunction V.2.fromSpec).homEquiv _ _ α`.
- `G := ⨁ V, (pushforward V.2.fromSpec).obj (tilde I)` and
  `ι := biproduct.lift φ`.
- Flasque: combine `isFlasque_biproduct`, `isFlasque_pushforward` and
  `tilde_isFlasque`.
- Quasi-coherent:
  - each summand by `isQuasicoherent_pushforward_of_qcqs`;
  - the sum by `ObjectProperty.prop_product` (instance
    `isQuasicoherent_isClosedUnderFiniteProducts`) and `biproduct.isoProduct`.
- Mono: use
  `(SheafOfModules.forget _).mono_of_mono_map (PresheafOfModules.mono_of_injective ...)`.
  - `(φ_V).app U` is `F.presheaf.map (homOfLE (image_preimage_le U)).op`
    followed by `α.app (f⁻¹ U)`. Use `Adjunction.homEquiv_unit`,
    `restrictAdjunction_unit_app_app` and `pushforward_map_app`.
  - `α.app` is injective by `modules_app_injective`.
  - So `ι.app U s = 0` makes `s` vanish on every `f_V(f_V⁻¹ U) ∋ x`. Then
    `s = 0` by `TopCat.Presheaf.section_ext`, as in
    `Scheme.Modules.section_eq_zero_of_locally`.
