# The exceptional ideal is invertible

## Status (partial, sorry-free)

Lean module: `Hartshorne.Scheme.BlowupExceptionalIdeal`. Proved:

- Chart algebra, for `S = A[It]` (`reesAlgebra I`, graded by `reesGrading I`), `a ∈ I` and
  `f = a t` (`Hartshorne.reesDegOne`), with `A → S_(f)` written `Hartshorne.reesAwayMap`:
  - `Hartshorne.reesAway_map_ideal_eq_span`: `I · S_(f) = (a)` (for `b ∈ I`, `b = a · (b t)/(a t)`);
  - `Hartshorne.reesAway_algebraMap_mem_nonZeroDivisors`: `a` is a non-zero-divisor of `S_(f)`;
  - `Hartshorne.reesTwistAwayToAway` (`S(1)_(f) → S_(f)`), `reesTwistAwayToAway_injective`,
    `range_reesTwistAwayToAway` (image `I · S_(f)`), `reesTwistAwayToAway_twistGenerator`
    (`f ↦ a`) and `reesTwistAwayToAway_mk` (the chart-free formula `y / s ↦ (y / t) / s`,
    with `y / t` = `Hartshorne.reesShift`, i.e. `Polynomial.divX`). This is the article's
    "Proof depends on" item.
- Charts of a relative Proj (generic in `S : QuasiCoherentGradedAlgebra X`):
  `QuasiCoherentGradedAlgebra.chartι` (`Spec S(U)_(f) ⟶ Proj_X S`), `chartMap`,
  `chartι_relProjToBase`, `chartSectionsIso`, `inverseImageIdeal_ideal_chart` (over `D₊(f)` the
  inverse image ideal is the image of `J(U)`), `exists_chartι_eq`.
- `Hartshorne.ReesAlgebraSheaf.isLocallyPrincipalNonZeroDivisor_inverseImageIdeal`: for any
  `J : X.IdealSheafData`, `π⁻¹J · 𝒪` on `Proj_X (⨁ Jᵈ)` is locally generated by one
  non-zero-divisor (no Noetherian or coherence hypothesis needed).
- Blowup level (`I : QuasicoherentIdealSubsheaf X`, `[IsNoetherian X]`, `hI` coherent):
  `QuasicoherentIdealSubsheaf.exceptionalIdeal` (`inverseImageIdeal π I`, equal to

  `quasicoherentIdealSubsheafEquiv_inverseImage`), `isLocallyPrincipalNonZeroDivisor_exceptionalIdeal`,
  `exceptionalDivisor` and `exceptionalDivisor_isEffective` (through

## Next route

1. On one `Proj S` with `S = A[It]`: a morphism `𝒪(1) ⟶ 𝒪` of modules. There is no nonzero graded
   `S`-linear map `S(1) → S` (it would be determined by the image of `1 ∈ S(1)_{-1}` in `S_{-1} = 0`),
   so use the submodule `S_+` graded as `S(1)` in degrees `≥ 0` and the `S`-linear map
   `divX : S_+ → S`. The fractions of `projGradedModuleSheaf` only use degrees in `ℕ`, so
   `S_+ ⊆ S(1)` induces an isomorphism of sheaves; `projGradedModuleSheafMap` gives the map
   to `S~ = projGradedModuleSheaf 𝒜 (gradedTwist 𝒜 0)`. The project has no
   `projTwistingSheaf 𝒜 0 ≅ 𝒪` yet; that is needed too. On the chart `D₊(a t)`, the map is
   `reesTwistAwayToAway` (via `ProjGradedModuleSheaf.chartIso`), so it is injective with image
   the inverse image ideal.
2. Compatibility with `QuasiCoherentGradedAlgebra.twistTransitionHom` along basic open
   inclusions of the base (both are defined through `twistFiber`, so this is a stalk-level check).
3. Gluing: `relTwistingSheaf` is `DirectedModuleGluing.DataTr.glue`, a subsheaf of compatible
   families in `∏ (projι U)_* 𝒪_U(1)`. A comparison into the glue, `G ⟶ glue` from compatible isos
   `G|_{Proj S(U)} ≅ 𝒪_U(1)`, is not in the project; it is the analogue of `ModuleGluing.θ`. Prove
   it is an isomorphism with `Scheme.Modules.isIso_of_isIso_restrictFunctor_map`.
A route that may be shorter for 1–2: the map `S(1)_(x) → S_(x)` is multiplication by the
degree `-1` element `t⁻¹ = a / (a t)` of the homogeneous localization `S_x`, which does not depend
on the choice of `a ∈ I` with `a t ∉ x` (`a · b t = b · a t`). On `D₊(a t)` it is the degree-zero
fraction `a / (a t)` of `S(-1)`, so `t⁻¹` is a global section of `𝒪(-1)` on `Proj A[It]`, and it is
compatible with base restriction because it is given by the same formula everywhere. A compatible
family of such sections is a global section of the glued `relTwistingSheaf (-1)`, with no gluing
of morphisms needed. Then `𝒪(1) ⟶ 𝒪(1) ⊗ 𝒪(-1) ≅ 𝒪(0)` (`twistMulIso` on each `Proj`). This still
needs `𝒪(0) ≅ 𝒪`, plus tensor-product compatibility on the relative Proj.

4. An alternative to 3: show `𝒪(1) ⟶ 𝒪_{X̃}` is mono with image the exceptional ideal, then copy
   the kernel-lift argument of `Scheme.CartierDivisor.toIdealSheaf` (Proposition 6.18), which
   works for any mono into `𝒪` whose image ideal is known on affine opens.

The optional bridge from `inverseImageIdeal` (`IdealSheafData.comap`) to the literal image of
`f^*I → 𝒪_Y`, which the reviewer of the Rees article flagged, was not needed for this partial work.
