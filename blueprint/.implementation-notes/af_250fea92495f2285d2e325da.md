# Projection from a point is a morphism

## Lean

Module `Hartshorne.Scheme.ProjectionFromPoint` (imports the coordinate-chart module
`Hartshorne.Scheme.CoordinateNonvanishingOpen`, `Hartshorne.RingedSpace.PicardGroup` for the
structure sheaf as an invertible module, and
`Hartshorne.Scheme.Differentials.RelativeDifferentialsBaseChange` for
`Scheme.Modules.pullbackComp_hom_unit` and `Scheme.Modules.pullback_map_unit`).

The statement is the coordinate form the article gives: `P = (0 : ⋯ : 0 : 1)`,
`H = {x_{n+1} = 0}` identified with `ℙⁿ_k` by `(x₀ : ⋯ : xₙ) ↦ (x₀ : ⋯ : xₙ : 0)`.
`ℙⁿ_k` is `projectiveSpaceOverScheme n (Spec (CommRingCat.of k))`; `k` is any field.

- `projectionDomain n Y`: `U = ⨆_{i ≤ n} D₊(xᵢ)` in `ℙⁿ⁺¹_Y` (any base `Y`).
- `projectionDomainTwist`, `projectionSections`: `𝒪(1)|_U` (pullback along `U.ι`) and the
  restrictions of `x₀, …, xₙ`; `isGeneratedBySections_projectionSections` (each `xᵢ`
  trivializes on `U.ι⁻¹ D₊(xᵢ)`, `isGeneratedBySections_of_isTrivializingSection`).
- `existsUnique_projection`, `projectionFromPoint`, `projectionFromPoint_spec`,
  `eq_projectionFromPoint_iff`: Theorem 7.1(b) applied to these sections.
- `projectivePoint k a ha`: the `k`-point `(a₀ : ⋯ : a_m)`, defined by Theorem 7.1(b) from the
  constants `aᵢ` as sections of `structureModule (Spec k) = SheafOfModules.unit _`;
  `eq_projectivePoint` (uniqueness), `projectivePoint_mem_projectiveSpaceChart_iff`
  (in `D₊(xᵢ)` iff `aᵢ ≠ 0`, via `preimage_projectiveSpaceChart_eq_nonvanishingLocusOpens`).
  `coordinatePoint k n` is `P`.
- `projectionDomain_eq_compl_range`: `U = (range P)ᶜ`. The hard direction is
  `eq_comp_coordinatePoint`: a morphism `g : T ⟶ ℙⁿ⁺¹_k` from a reduced scheme avoiding `U` is
  `(g ≫ proj) ≫ P`. On `T` the pulled-back `x₀, …, xₙ` have empty nonvanishing locus, so
  `x_{n+1}` trivializes `g^* 𝒪(1)` on `T` and the others are zero (reducedness); an iso
  `g^* 𝒪(1) ≅ c^* 𝒪_{Spec k}` comes from `Ringed.exists_iso_of_frames`, and Theorem 7.1
  uniqueness concludes. Applied to `Spec κ(x) ⟶ ℙⁿ⁺¹_k` (`mem_range_coordinatePoint`).
- `exists_iso_of_comp`: if `φ` is defined by `(L, s)`, then `f ≫ φ` is defined by
  `(f^* L, f^* s)` (from `pullbackComp_hom_pullbackGlobalSection`,
  `pullbackComp_inv_pullbackGlobalSection`, `pullback_map_pullbackGlobalSection`).
- `hyperplaneInclusion n Y`: defined by the sections `x₀, …, xₙ, 0` (`Fin.lastCases 0 _`);
  `hyperplaneInclusion_notMem_projectiveSpaceChart_last` (image in `H`);
  `projectivePoint_comp_hyperplaneInclusion`.
- `exists_lift_projectivePoint_comp_projectionFromPoint` (`π(a₀ : ⋯ : a_{n+1}) =
  (a₀ : ⋯ : aₙ)`), `exists_lift_projectivePoint_comp_projectionFromPoint_hyperplaneInclusion`
  (its image in `H` is `a − a_{n+1} e_{n+1}`, the point of the line `PQ` on `H`).
- `projectionFromPoint_isProjection`: the summary conjunction.

## Scope

- The general point `P` and hyperplane `H` of the book are reduced to the coordinate case by a
  projective change of coordinates; the project has no linear automorphisms of `ℙⁿ_k` yet, so
  only the coordinate case is formalized.
- That `hyperplaneInclusion` is a closed immersion onto `H` (so `H ≅ ℙⁿ_k`) is not proved; it
  would follow from Hartshorne II, Proposition 7.2 (the projective closed-immersion chart
  criterion article), which is not yet formalized.
- The geometric description `π(Q) = PQ ∩ H` is stated on `k`-rational points.
