# Stalks of the pullback of a module sheaf

## Status

Already formalized in the project, sorry-free and imported by the library
root, but not yet recorded: this article was split off from
`module-sheaf-flat-base-change` by a roadmap revision, and a later Formalize
pass should record `lean:`, `statement:` and `proof:` after independent
review of the statement.

## Candidate Lean (module `Hartshorne.Scheme.ModulePullbackStalk`)

For `h : X' ⟶ X` a morphism of schemes and `x' : X'`:

- `Hartshorne.pullbackStalkIso h x' : Scheme.Modules.pullback h ⋙ moduleStalkFunctor x' ≅ moduleStalkFunctor (h x') ⋙ ModuleCat.extendScalars (h.stalkMap x').hom`,
  the natural isomorphism.
- `Hartshorne.pullbackStalkLinearEquiv h x' F`, the same as an
  `𝒪_{X',x'}`-linear equivalence for one `F`.

Supporting: `pushforwardSkyscraperIso` (direct image of a skyscraper),
`pullbackStalkAdjunction`, `stalkExtendScalarsAdjunction`. The proof is by
`Adjunction.leftAdjointUniq`, using Mathlib's
`Scheme.Modules.pullbackPushforwardAdjunction` and
`ModuleCat.extendRestrictScalarsAdj`.

## Source note

Origin is `bridged`: Hartshorne II.5 (pp.109–110) defines
`f^*G = f^{-1}G ⊗_{f^{-1}O_Y} O_X` but does not state the stalk formula as a
result. The Lean proof does not use the module tensor-product article, so
that article is not a proof dependency.
