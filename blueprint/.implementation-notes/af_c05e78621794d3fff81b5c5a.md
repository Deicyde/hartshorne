# Projective bundles

## Status

Not formalized. Deferred: the missing piece is the bridge described below.

## Missing piece: Sym(E) on the affine site

Relative Proj (`Hartshorne.RelativeProjData.relativeProj`) takes a
`Hartshorne.QuasiCoherentGradedAlgebra X`. That structure records graded rings
of sections over the affine opens of `X`, with restrictions along basic opens
and the condition `S(D(r)) = S(U)_r` (`NatTrans.Coequifibered`).

The graded symmetric algebra is instead a sheaf-level object,
`AlgebraicGeometry.Scheme.Modules.symmetricAlgebra` with
`symmetricAlgebraStructure` and `symmetricAlgebra_graded`, defined over all
opens. Before `P(E) = Proj_X Sym(E)` can be defined, a bridge must turn it into
a `QuasiCoherentGradedAlgebra`:

1. For affine `U`, make `Γ(U, Sym E)` a commutative ring, using the
   multiplication `symmetricAlgebraStructure.mul`. Check that restriction is a
   ring map.
2. Grade it: `Γ(U, Sym E) = ⊕_d Γ(U, Sym^d E)` for affine (quasi-compact) `U`.
   Sections of the sheaf direct sum over a quasi-compact open are the direct
   sum of the sections.
3. Coequifibered: `Γ(D(r), Sym E) = Γ(U, Sym E)_r`. This follows from
   quasi-coherence of each `Sym^d E`
   (`symmetricPower_isQuasicoherent`, then localization of sections of a
   quasi-coherent module along basic opens).
4. Check Hartshorne's hypotheses (`RelativeProjData`):
   - degree zero is `𝒪_X` (`symmetricPowerZeroIso`);
   - degree one is coherent (`symmetricPowerOneIso`, `symmetricPower_isCoherent`);
   - `Sym E` is generated in degree one (`epi_moduleSheafTensorToSymmetricAlgebra`).

Alternatively, define the affine-site algebra directly as
`U ↦ Sym_{Γ(U)} Γ(U, E)` and compare it with the sheaf on affines.

After the bridge, the free case (`P(E)|_U ≅ ℙⁿ_U` compatibly with the
projection and `𝒪(1)`) uses `symmetricAlgebra_restrict_iso_polynomial`, the
projective-space-over-a-scheme API, and `relTwistingSheafAffineIso`.
