# Open extension by zero properties

The checked conditional-presheaf implementation proves the on- and off-open
stalk isomorphisms using `TopCat.Presheaf.exists_le_germ_eq`,
`TopCat.Presheaf.stalkFunctor_map_unit_toSheafify_isIso`, and
`TopCat.Presheaf.stalkPushforward.stalkPushforward_iso_of_isInducing`.

Use the adjunction in `af_813ed5a3017d80bd70095202` to identify the unit
`r_F : j^*j_!F ≅ F`. The compatibility data in the uniqueness clause are
essential. Bare "unique up to unique isomorphism" is false when `F` has a
nontrivial automorphism. For a candidate `ρ : j^*G ≅ F`, the required
equation is exactly `j^*(e.hom) ≫ ρ.hom = r_F.hom`.
