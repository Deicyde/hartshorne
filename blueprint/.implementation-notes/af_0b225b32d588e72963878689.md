# Projective-space bundles

## Lean

Module `Hartshorne.Scheme.ProjectiveSpaceBundle`.

- `AlgebraicGeometry.ProjectiveSpaceBundle f n`: structure (data) modelled on
  `AlgebraicGeometry.GeometricVectorBundle`. Fields: index type `ι`, opens `U`, `iSup_eq_top`,
  trivializations `ψ i : f⁻¹(U i) ≅ projectiveSpaceOverScheme n (U i)` with `ψ_over`, and `linear`:
  for every affine open `V ≤ U i ⊓ U j` there is `g : GL (Fin (n+1)) Γ(X, V)` with
  `chart_j ≫ (ψ j).inv ≫ ι_j = (projLinearAut Γ(X, V) n g).hom ≫ chart_i ≫ (ψ i).inv ≫ ι_i`,
  i.e. `ψ_i ∘ ψ_j⁻¹ = Proj θ_g` on `ℙⁿ_V`.
- `linearSubstitutionGradedHom A n a`: graded endomorphism `x_k ↦ ∑_l a k l * x_l` of
  `A[x₀..xₙ]` (`aeval`); composition multiplies matrices (`..._comp_apply`: `θ_a ∘ θ_b = θ_{b a}`),
  bijective for `a ∈ GL`.
- `projLinearAut A n g := projIsoOfBijective (linearSubstitutionGradedHom A n g) _`, hom is
  `Proj.map θ_g`.
- `projectiveSpaceAffineChart n V hV h : Proj Γ(X,V)[x] ⟶ ℙⁿ_U`: `projectiveSpaceOverSpecIso`
  (identity renumbering), then `projectiveSpaceOverSchemeMap n hV.isoSpec.inv`, then the map
  induced by `V ⊆ U`. This is the same identification used inside `projectiveBundleFrameIso`.
- `Scheme.Modules.frameGradedHom_comp_linearSubstitution`: two frames `e, e'` over an affine `V`
  give `g ∈ GL` with `frameGradedHom e' ∘ θ_g = frameGradedHom e` (from
  `chartRingHom_transition` both ways, invertibility from injectivity of `frameGradedHom`).
- `Scheme.Modules.projectiveBundleAtlas hE hfin hrank` (`hrank : ∀ x, E.rankAt x = (n+1 : ℕ)`):
  covering indexed by `AffineFrame E (n+1)` (from `GeometricVectorBundle`), trivializations are
  the `choose` of `exists_projectiveBundleIso_of_frame`, whose restriction clause to affine
  `V ⊆ U` gives `chart ≫ ψ⁻¹ ≫ ι = (projIsoOfBijective (frameGradedHom e|_V)).inv ≫ restrictIso⁻¹ ≫ ι`
  (private `projectiveSpaceAffineChart_inv`). The transition then reduces to `Proj.map_comp`.
- `Scheme.Modules.nonempty_projectiveSpaceBundle_projectiveBundleProj`: the theorem.

## Notes

- Transition condition is stated on affine opens inside overlaps with coefficients in `Γ(V, 𝒪)`,
  as in the exercise's own formulation (and as in the geometric vector bundle definition), not
  with one matrix over the possibly non-affine overlap.
- `hfin` is kept as an argument because `projectiveBundleProj` takes it; it follows from `hrank`.
- Converse (Ex. 7.10(c)) and the Picard classification are not in scope.
