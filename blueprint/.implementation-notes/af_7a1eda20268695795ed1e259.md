# Affine quasi-coherent sheaves are acyclic

## Supporting implementation references

- `ModuleCat`

## Lean

- Statement: `Hartshorne.sheafCohomology_isZero_of_isQuasicoherent_spec` in
  `Hartshorne/Cohomology/AffineQuasicoherentAcyclic.lean`, for `A : CommRingCat` with
  `[IsNoetherianRing A]`, `F : (Spec A).Modules` with `[F.IsQuasicoherent]`, and `0 < i`;
  the cohomology is `sheafCohomology (Spec A).toTopCat i` of
  `(SheafOfModules.toSheaf (Spec A).ringCatSheaf).obj F`, the convention of
  `Hartshorne.IsCohomologicalDimensionBound`.
- Proof: dimension shifting along `0 ⟶ M~ ⟶ I~ ⟶ (I/M)~ ⟶ 0` with `I = Injective.under M`
  (`Hartshorne.AffineAcyclic.isZero_tilde`), using `affineTilde_exact`,
  `ModuleCohomology.toSheaf_preservesFiniteColimits` (through `ShortExact.map_of_exact`),
  `tilde_isFlasque`, `sheafCohomology_isZero_of_isFlasque`, `rightDerived_exact₁`, and
  `tilde.toOpen_map_app` for surjectivity of `Γ(I~) ⟶ Γ((I/M)~)`; then
  `isQuasicoherent_iff_isIso_fromTildeΓ` transports to `F`.

## Friction

- `Scheme.Modules X` is a `def` with its own category instances, so functors typed on
  `SheafOfModules X.ringCatSheaf` (such as `ModuleCohomology.toTopSheaf`) do not find
  `PreservesZeroMorphisms` for short complexes in `X.Modules`. Retyping the short complex as
  `ShortComplex (SheafOfModules _)` (by ascription) and typing the functor with domain
  `X.Modules` (for `mapIso`) both work.
- `tilde.functor A` lands in `(Spec (.of A)).Modules`; working internally over `Spec (.of A)`
  avoids instance mismatches with `Spec A`.

## Possible follow-up

- A version for an affine Noetherian scheme `X` (not literally `Spec A`), useful for affine
  covers, needs transport along `X ≅ Spec Γ(X, ⊤)` of both the module and the cohomology.
