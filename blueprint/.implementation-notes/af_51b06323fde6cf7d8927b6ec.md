# Nonsingular curves over a field

## Candidate Lean (not yet recorded)

The project already has Lean for this article. It is not recorded in the
frontmatter: a later Formalize pass should record it after independent review.
All three declarations are in the module
`Hartshorne.Scheme.FiniteCurveDivisorPullback`, namespace
`AlgebraicGeometry.Scheme`, and the module is sorry-free.

- `IsNonsingularCurve`: the curve predicate. It is a `structure` in `Prop`, so
  the article's `declaration: structure` matches.
- `IsNonsingularCurve.satisfiesConditionStar`: such a curve satisfies
  condition $(*)$. Its conclusion is `X.SatisfiesConditionStar`, from the
  regularity-in-codimension-one article.
- `IsNonsingularCurve.isClosed_singleton_iff_coheight_eq_one`: a point is
  closed if and only if it has coheight one. Coheight-one points are the
  support of the project's Weil divisors, so this is the identification of
  closed points with prime divisors.

The module also has public helpers on the way to the third result:
`IsNonsingularCurve.krullDim_eq_one`, `IsNonsingularCurve.coheight_eq_one_iff`
(coheight one if and only if not the generic point), and
`IsNonsingularCurve.exists_ne_genericPoint`. These are supporting declarations,
not candidates for `lean:`.

## Comparing the Lean definition with Hartshorne's wording

Things for the Formalize pass to check:

1. **Integrality sits outside the predicate.** Hartshorne's curve is
   integral. `IsNonsingularCurve k X` has no integrality field, and
   integrality comes in separately as the instance `[IsIntegral X]`. Both
   theorems take `[IsIntegral X]`, so the pair
   `[IsIntegral X] (hX : X.IsNonsingularCurve k)` is faithful. The predicate
   alone is not Hartshorne's notion, and its docstring says so. The recording
   pass should either accept this split and state it in one sentence of the
   article, or ask Formalize to add an `isIntegral` field.
2. **Finite type is split into two fields.** The structure asks for
   `LocallyOfFiniteType (X ↘ Spec k)` and `QuasiCompact (X ↘ Spec k)`. The
   finite-type article proves the same characterization (locally of finite
   type and quasi-compact), so this is faithful.
3. **Separatedness is relative.** The field is `IsSeparated (X ↘ Spec k)`,
   which is separated over $k$, as Hartshorne requires.
   `satisfiesConditionStar` derives absolute separatedness by composing with
   the terminal morphism.
4. **Dimension.** The field is `topologicalKrullDim X = 1`. That matches the
   scheme-dimension article, whose Mathlib declaration is
   `topologicalKrullDim`.
5. **Regularity.** The field is
   `∀ x, IsRegularLocalRing (X.presheaf.stalk x)`. That is Hartshorne's "all
   local rings regular" read literally. It does not reuse the project's
   `AlgebraicGeometry.Scheme.IsRegular`, whose definition also asks for
   `IsLocallyNoetherian X`; here local Noetherianity follows from finite type.
   The two notions agree, and either is acceptable.
6. **The ground field.** `k` is any field, with `[X.Over (Spec (.of k))]`.
   Hartshorne's algebraically-closed hypothesis is not part of the predicate,
   which agrees with the article's last paragraph.
7. **Closed points versus prime divisors.** The theorem is stated with
   `Order.coheight x = 1`, not with the `PrimeDivisor` type. The Weil divisor
   group article identifies prime divisors with coheight-one points, so this
   is the article's statement in the project's representation.
