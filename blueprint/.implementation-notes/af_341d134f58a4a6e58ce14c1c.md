# The Picard group of projective space

## Revision (review r9 item 53(b))

Corollary II.6.17 (p.145) has no hypothesis `n ≥ 1`. The statement now asserts
existence (every invertible sheaf on `P^n_k` is `O(l)` for some `l`) for all
`n ≥ 0`, including `P^0_k = Spec k`, and keeps `n ≥ 1` only for the uniqueness of
`l` and for `Pic(P^n_k) ≅ ℤ`. The article was retracted for this revision.

The existing Lean (`Hartshorne/Scheme/ProjectiveSpacePicard.lean`) does not cover
`n = 0`: `Hartshorne.exists_unique_iso_projTwistingSheaf`,
`Hartshorne.projectiveSpacePicardEquiv` and
`Hartshorne.projectiveSpacePicardEquiv_projTwistingSheaf` all take `hn : 0 < n`.
Those three still prove the `n ≥ 1` clauses.

To re-record, a Formalize pass must add an existence theorem without `0 < n`:
for every `n : ℕ` and invertible `L` on `Proj 𝒜` (the `ℙⁿ_k` of that file),
`∃ l : ℤ, Nonempty (L ≅ projTwistingSheaf 𝒜 l)`. For `0 < n` it follows from
`exists_unique_iso_projTwistingSheaf`. For `n = 0`, `Proj` of `k[x₀]` is
`Spec k` (one point), so an invertible module sheaf is free of rank one, hence
isomorphic to `projTwistingSheaf 𝒜 0 ≅ 𝒪`. The `n = 0` case needs an
identification of `Proj k[x₀]` with a one-point scheme, or a direct argument
that its invertible sheaves are trivial. Then record that theorem together with
the three existing declarations.
