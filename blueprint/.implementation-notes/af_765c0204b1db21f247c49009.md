# Infinitesimal fibres

## Lean implementation

Module `Hartshorne.Cohomology.InfinitesimalFibers`.

- Indexing: `n : ℕ` with stage `n` cut out by `m_y ^ n` (the book's index). Stage `0` is the
  empty scheme (`O_{Y,y} ⧸ m_y ^ 0 = 0`); results that need `n ≥ 1` take `1 ≤ n` (or `[NeZero k]`
  for instances). Consumers wanting an `ℕ`-indexed inverse system starting at `X_1` reindex by
  `n + 1`.
- `infinitesimalFiber f y n := baseExtension f (InfinitesimalFiber.toScheme y n)`, where
  `toScheme y n : Spec (O_{Y,y} ⧸ m_y ^ n) ⟶ Spec O_{Y,y} ⟶ Y` (`Y.fromSpecStalk y`).
  Projections `infinitesimalFiberι` (to `X`) and `infinitesimalFiberToSpec`.
- Transitions are defined for all `k ≤ n` (`infinitesimalFiberTransition`, with `_refl` and
  `_comp`); Hartshorne's `X_n ⟶ X_{n+1}` is the case `n ≤ n + 1`.
  `infinitesimalFiberTransition_isPullback` is the pasting of the defining pullback squares, and
  gives `isClosedImmersion_infinitesimalFiberTransition` by base change.
- Module maps: pullback form `infinitesimalFiberModulePullbackIso` (`(X_k ⟶ X_n)^* F_n ≅ F_k`,
  from `Scheme.Modules.pullbackComp`), and its adjoint `infinitesimalFiberModuleMap :
  F_n ⟶ (X_k ⟶ X_n)_* F_k`. `isCoherent_infinitesimalFiberModule` uses `isCoherent_pullback`.
- `X_1 ≅ X_y`: `infinitesimalFiberOneIso` into Mathlib's `Scheme.Hom.fiber`, induced by
  `O_{Y,y} ⧸ m_y ^ 1 ≅ κ(y)` (`Ideal.quotEquivOfEq (pow_one _)`), with
  `infinitesimalFiberOneIso_hom_fiberι` (over `X`).
- Same space: `InfinitesimalFiber.subsingleton_spec_thickeningRing` (one point, nonempty for
  `n ≥ 1`) makes `Spec (O/m^k) ⟶ Spec (O/m^n)` surjective, hence so is its base change;
  `isHomeomorph_infinitesimalFiberTransition` (`1 ≤ k ≤ n`), `infinitesimalFiberHomeomorph`
  (`X_y ≃ₜ X_n`), `range_infinitesimalFiberι` (image `f ⁻¹ {y}`).
- Not proved: a coherence lemma for the module maps along `X_j ⟶ X_k ⟶ X_n` (the pullback isos
  are built from `pullbackComp`, so it reduces to the pseudofunctor coherence of pullbacks).
- The infinitesimal-neighbourhoods article's declarations are not used.
