# Coordinate nonvanishing opens

## Lean

Module `Hartshorne.Scheme.CoordinateNonvanishingOpen` (imports the Theorem 7.1 module
`Hartshorne.Scheme.MorphismFromGeneratedLineBundle`, which it leaves unchanged).

The base is an arbitrary scheme `Y` (the book's `Spec A` is the special case). The morphism is
any `φ : X ⟶ ℙⁿ_Y` with an isomorphism `e : φ^* 𝒪(1) ≅ L` carrying each `φ^* xᵢ` to `sᵢ`
(`he`); by `existsUnique_morphism_of_isGeneratedBySections` this characterizes the morphism
defined by generating sections. `L.IsInvertible` is kept so that `X_{sᵢ}` is available as an
open (`nonvanishingLocusOpens`); generation by the `sᵢ` is not needed once `e` is given.

- `projectiveSpaceChart n Y i`: `D₊(xᵢ) ⊆ ℙⁿ_Y`, the preimage of `chartInt n i` under
  `toProjInt n Y : ℙⁿ_Y ⟶ ℙⁿ_ℤ`.
- `projectiveSpaceChartRatio n Y i j`: `xⱼ/xᵢ` on it, `(toProjInt n Y).app _ (ratioInt n i j)`.
- `restrict_projectiveSpaceCoordinate_eq_smul`, `isTrivializingSection_projectiveSpaceChart`:
  `xⱼ = (xⱼ/xᵢ) xᵢ` on `D₊(xᵢ)`, and `xᵢ` trivializes `𝒪(1)` there (so the ratio is the
  intrinsic one).
- `preimage_projectiveSpaceChart_eq_nonvanishingLocusOpens`: `φ⁻¹ D₊(xᵢ) = X_{sᵢ}`
  (from `chartPreimage_eq_locus`).
- `appLE_projectiveSpaceChartRatio_smul`: `φ^#(xⱼ/xᵢ) · sᵢ = sⱼ` on `X_{sᵢ}`, via `appLE`
  (from `appLE_ratioInt_of_iso` and `Scheme.Hom.comp_appLE`).
- `existsUnique_chartRingHom_of_iso`: there is a unique ring map
  `F : ℤ[x]_{(xᵢ)} → Γ(X_{sᵢ}, 𝒪_X)` with `F(xⱼ/xᵢ) · sᵢ = sⱼ`, and
  `X_{sᵢ}.ι ≫ φ ≫ toProjInt n Y = X_{sᵢ}.toSpecΓ ≫ Spec.map F ≫ Proj.awayι _ (X i) _ _`
  (from `ι_comp_eq_toSpecΓ_SpecMap`; uniqueness by `chart_ringHom_ext`,
  `ulift_int_ringHom_ext` and `eq_of_smul_eq`). The ring is `ℤ[x₀/xᵢ, …, xₙ/xᵢ]`; over
  `ℙⁿ_Y = ℙⁿ_ℤ ×_ℤ Y` the `Y`-component of the restriction is just `X_{sᵢ}.ι ≫ φ ≫ proj`, so
  this is the base-`Y` form of the book's `A[xⱼ/xᵢ] → Γ(X_{sᵢ}, 𝒪_X)`.
