# Implementation note: coherent modules on a Noetherian formal scheme

Lean module: `Hartshorne.Scheme.CoherentFormalModule`.

- `Hartshorne.IsCoherentFormalModule F` for `F : SheafOfModules (structureRingCatSheaf X.toLocallyRingedSpace)`
  and `X : NoetherianFormalScheme`: there are a finite index type `ι : Type`, opens `U i` with
  `iSup U = ⊤`, and for each `i` a Noetherian scheme `Y`, a `QuasicoherentIdealSubsheaf Y` `I`, an
  isomorphism `e : X.restrict (U i).isOpenEmbedding ≅ I.formalCompletion` and `G : Y.Modules` with
  `IsCoherent G` and `(structureModuleRestrict X (U i).isOpenEmbedding).obj F ≅
  (structureModulePushforward e.inv).obj (I.moduleCompletion G)`.
- The cover, the charts and the ambient schemes are chosen freely: they need not be the ones
  witnessing `IsNoetherianFormalScheme`, and the ambient schemes need not be affine (Hartshorne's
  p. 194 definition asks for charts that are completions of Noetherian schemes, with no affineness;
  same convention as `IsNoetherianFormalScheme`). The index universe is `Type`, as there.
- Helpers (public, used in the statement):
  - `structureRingCatSheaf X`: `(sheafCompose _ (forget₂ CommRingCat RingCat)).obj X.sheaf` for a
    `LocallyRingedSpace`; for `I.formalCompletion` it is definitionally
    `I.formalCompletionRingCatSheaf`, so `I.moduleCompletion G` is a module over it with no cast.
  - `structureRingCatSheafHom f`: `whiskerRight f.c (forget₂ _ _)`, the LRS analogue of Mathlib's
    `Scheme.Hom.toRingCatSheafHom`.
  - `structureModulePushforward f`: `SheafOfModules.pushforward (structureRingCatSheafHom f)`.
    Transport along a chart `e` is pushforward along `e.inv`.
  - `structureModuleRestrict X h`: `SheafOfModules.pushforward` along `h.functor` with the identity
    ring map (the restricted LRS has presheaf `h.functor.op ⋙ X.presheaf` definitionally). The
    continuity instance must be stated on `(X.restrict h).carrier`, not on `U`, for instance
    search to find it.
- Sanity: `IsCoherentFormalModule.of_iso`, `IsCoherentFormalModule.iso_iff` (invariance under
  module isomorphism).

Not done (the article's proof-depends-on bullet): independence of the chosen finite cover by
completion charts, i.e. that coherence can be tested on any such cover / refinement. It is not
needed to state the definition.
