## Lean

Module `Hartshorne.Cohomology.QuasiProjectiveLocallyFreeResolution`.

- Main statement: `Hartshorne.exists_quasiIso_locallyFreeResolution_of_quasiProjective`. For
  `f : X ⟶ Spec A` with `QuasiProjective f` and `A` Noetherian, and `F` coherent, it gives a
  `ChainComplex X.Modules ℕ` with a quasi-isomorphism to `(ChainComplex.single₀ _).obj F`, with
  every term `Ringed.IsFiniteLocallyFree`. This is the input format of
  `Hartshorne.Ringed.sheafExtIsoHomologyOfLocallyFreeResolution`. The file sets the same local
  instance (`Abelian.toPreadditive` at priority 2000) as that file, so the chain complex is
  stated with the same zero morphisms.
- "Quasi-projective over a Noetherian affine scheme" is encoded with the project's
  `Hartshorne.QuasiProjective` (an open immersion followed by a `Projective` morphism) over
  `Spec A`, with `IsNoetherianRing A`.

## Helpers (in `Hartshorne.QuasiProjectiveResolution`)

- `exists_quasiIso_toSingle₀`: in any abelian category, if every object with property `P` has an
  epimorphism from an object with property `Q` whose kernel has `P`, then every `P`-object has an
  `ℕ`-indexed resolution by `Q`-objects. It is built from the successive kernels (`stage`,
  `complex`, `augmentation`, `quasiIso_augmentation`).
- `isInvertible_tensorZPow`: integer tensor powers of an invertible sheaf are invertible.
- `isLocallyFreeOfRank_sigma_of_isInvertible`: a finite coproduct of invertible sheaves is
  locally free of rank the number of summands. Frames of all the summands near a point are
  restricted to a common open.
- `exists_epi_isFiniteLocallyFree`: the first step, following Hartshorne's proof. Extend `F` to
  a coherent sheaf on the projective `Z`, apply II.5.18, and pull back along the open immersion.
  The kernel is coherent because `X` is locally Noetherian.
