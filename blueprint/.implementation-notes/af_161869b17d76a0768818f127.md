# The project formal-spectrum bridge

## Lean

Module `Hartshorne.Scheme.FormalSpectrum` (imports only `Hartshorne.Scheme.FormalCompletion`).

- `Hartshorne.specIdealSubsheaf A I` (`A : Type u`, `[CommRing A]`, `I : Ideal A`): the
  `QuasicoherentIdealSubsheaf (Spec (CommRingCat.of A))` attached to `I`, defined as
  `quasicoherentIdealSubsheafEquiv.symm` of the Mathlib kernel ideal data
  `(Spec.map (CommRingCat.ofHom (Ideal.Quotient.mk I))).ker`, i.e. the ideal sheaf of the closed
  subscheme `Spec (A ⧸ I) ⟶ Spec A` (the affine-closed-subschemes edge).
- `Hartshorne.Spf A I` with `[IsNoetherianRing A]`: `(specIdealSubsheaf A I).formalCompletion`,
  a `LocallyRingedSpace.{u}`. The Noetherian instance is kept (anonymous binder) because the
  article states it; the construction does not use it, so Batteries' `unusedArguments` reports
  it on `Spf`. That finding is the intended kept hypothesis.
- `Hartshorne.IsAffineNoetherianFormalScheme X` for `X : LocallyRingedSpace.{u}`:
  `∃ (A : Type u) (_ : CommRing A) (_ : IsNoetherianRing A) (I : Ideal A), Nonempty (X ≅ Spf A I)`
  (isomorphism in `LocallyRingedSpace`).

Sanity API:

- `isClosedImmersion_spec_map_quotient_mk` (instance): Mathlib's `spec_of_quotient_mk` is stated
  for `I : Ideal R` with `R : CommRingCat`, and does not fire for `I : Ideal A` with
  `CommRingCat.of A`.
- `specIdealSubsheafNeighborhoodOneIso A I : Y_1 ≅ Spec (A ⧸ I)` and its `_hom_comp`
  compatibility with the closed immersions (from `infinitesimalNeighborhoodOneIso`).
- `range_specIdealSubsheaf_infinitesimalNeighborhoodι`: the support of `Y_1` in `Spec A` is
  `PrimeSpectrum.zeroLocus I`, i.e. `V(I)`.
- `Spf_carrier` (rfl), `spfHomeomorph : (Spf A I).carrier ≃ₜ Spec (A ⧸ I)`.
- `isAffineNoetherianFormalScheme_Spf`, `IsAffineNoetherianFormalScheme.of_iso`.
