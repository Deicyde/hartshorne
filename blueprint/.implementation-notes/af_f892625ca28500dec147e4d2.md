# Skyscraper module sheaves and the stalk adjunction

## Status

Already formalized in the project, sorry-free and imported by the library

## Candidate Lean (module `Hartshorne.RingedSpace.ModuleSkyscraper`)

For a ringed space given by `X : TopCat` and a sheaf
`R : Sheaf (Opens.grothendieckTopology X) CommRingCat`, and `x : X`:

- `Hartshorne.Ringed.moduleSkyscraper x : ModuleCat (ringSheafStalk R x) ⥤ SheafOfModules (ringCatSheafOf R)`,
  the skyscraper functor (object `moduleSkyscraperObj`, sheaf condition
  `skyscraperAbPresheaf_isSheaf`, morphisms `moduleSkyscraperMap`). Sections
  over `U` are functions `PLift (x ∈ U) → N`, which avoids case splits.
- `Hartshorne.Ringed.moduleStalkFunctor x`, the stalk as an
  `𝒪_{X,x}`-module, functorially (`moduleStalkFunctor_map_germ`).
- `Hartshorne.Ringed.moduleStalkSkyscraperAdjunction x : moduleStalkFunctor x ⊣ moduleSkyscraper x`,
  with `moduleStalkSkyscraperAdjunction_homEquiv_apply` (the formula for the
  correspondence in the statement).

Record the three main names in `lean:`; the rest are supporting.

## Prior art

Pinned Mathlib `Mathlib/Topology/Sheaves/Skyscraper.lean` has the skyscraper
sheaf with values in a category `C` (`skyscraperSheaf`) and
`stalkSkyscraperSheafAdjunction`, but no `SheafOfModules` version over the
stalk ring; the project construction is the module-level one.

Duplication follow-up (not part of this revision):
`src/Hartshorne/Cohomology/SmoothMorphisms/EtaleCriteria.lean` (around lines
246-306) builds the skyscraper object for schemes again (`skyAb`,
`skyAb_isSheaf`, `skyModule`, `skyMod`). Rewrite `EtaleCriteria.skyMod` as
`moduleSkyscraperObj (R := X.sheaf)` and delete the copies.

Type note: the stalk ring here is `ringSheafStalk R x`; for a scheme it is
defeq to `X.presheaf.stalk x` but not at instance transparency.

## Source note

Origin is `bridged`. Hartshorne defines skyscraper sheaves of abelian groups
in Exercise II.1.17 (outside the adopted exercise set) and uses the module
version and the stalk adjunction inside the proof of Proposition III.2.2
(p.207), without stating it as a numbered result. The III.2.2 usage is
recalled from the book; the summary source file does not spell it out.
The formalized enough-injectives article does not use this construction (its
Lean proof goes through a Grothendieck-category argument), so no edge was
added there; an `Informally uses` link from it would be accurate.
