# An ample sheaf has a very ample power

## Status

Statement and proof in Lean (candidate, pending review). Module
`Hartshorne.Scheme.AmpleVeryAmplePower`.

```lean
theorem AlgebraicGeometry.Scheme.Modules.IsAmple.exists_isVeryAmpleRelative_moduleSheafTensorPower
    {A : CommRingCat.{u}} [IsNoetherianRing A] (f : X ⟶ Spec A) (hf : FiniteType f)
    {L : X.Modules} (hL : haveI := finiteType_isNoetherian f hf; L.IsAmple) :
    ∃ k > 0, IsVeryAmpleRelative f (moduleSheafTensorPower k L)
```

## Route (Hartshorne's printed proof)

- Affine cover: `IsAmple.exists_isAffineOpen_nonvanishingLocus_of_finiteType` gives a finite
  set of sections `sᵢ` of `L' = L^{⊗ n}` with affine nonvanishing loci covering `X`.
- Finite generation: `HasRingHomProperty.appLE` for `LocallyOfFiniteType` gives each
  `Γ(X_{sᵢ}, 𝒪_X)` as a finite-type `Γ(Spec A, ⊤)`-algebra; a finite generating set `G i` is
  taken, and `Algebra.adjoin_eq_ring_closure` turns it into a subring-closure statement.
- Lemma 5.14(b): `exists_forall_sectionPowSMul_extension` (the every-large-degree form of
  `exists_sectionPowSMul_extension`) with `F = 𝒪_X` (`structureModuleOf X`, quasi-coherent by
  `ClosedImmersionIdeal.isQuasicoherent_unit`), cover the `X_{sᵢ}` themselves, trivializing
  sections `sᵢ|`, and quasi-compact overlaps from Noetherianity. One `m` serves every generator.
- The sheaf is `M = 𝒪_X ⊗ L'^{⊗ m}` (`tensorPowerTwist`), identified with `L^{⊗ nm}` at the end
  by `Ringed.moduleSheafUnitTensor` and `Ringed.moduleSheafTensorPowerMulIso`.
- Sections: `none ↦ 0` (so the index type is never empty), `sᵢ^m = sectionPowSMul … sᵢ 1`, and the
  extensions `c_{i b}`; indexed by `Fin (N + 1)` via `Fintype.equivFinOfCardEq`.
- Private lemmas: `1 ⊗ e^{⊗ m}` trivializes `M` where `e` trivializes `L'`
  (`IsTrivializingSection.moduleSheafTensorPower` transported along the unit isomorphism), and
  `X_{sᵢ^m} = X_{sᵢ}` for `m > 0`.
- Theorem 7.1 (`existsUnique_morphism_of_isGeneratedBySections`) gives `φ : X ⟶ ℙᴺ_{Spec A}`.
- One chart of Proposition 7.2 (private `isClosedImmersion_morphismRestrict_chart`): over
  `D₊(x)` of the coordinate `sᵢ^m`, the preimage is the affine `X_{sᵢ}` and the ring map hits
  `A` and each `b = c_{i b}/sᵢ^m`, so `φ ∣_ D₊(x)` is a closed immersion
  (`isClosedImmersion_morphismRestrict_iff`, `appLE_projectiveSpaceChartRatio_smul`). The recorded
  Proposition 7.2 is stated for all charts of `ℙᴺ`, while the book applies it over the open union
  of the charts of the `sᵢ^m`; the chart-wise criterion behind it is used instead.
- Private `isImmersion_of_isClosedImmersion_morphismRestrict`: closed immersion over each of
  several opens whose preimages cover `X` gives a closed immersion into their union
  (`IsZariskiLocalAtTarget`, `morphismRestrictRestrict`), hence an immersion.

## Immersion shape

`IsVeryAmpleRelative` asks for an open immersion followed by a closed immersion. The book's
morphism is a closed immersion into an open subscheme. Since `X` is Noetherian, `φ` is
quasi-compact (`quasiCompact_of_noetherianSpace_source`), so `φ.toImage` is an open immersion and
`φ.imageι` a closed immersion (as in Exercise 5.12(a)'s Lean). No gap arises here.
